# 第二十一章 因缘果报的修行之法

完全读懂杂阿含经

有个时候，佛陀住在舍卫国的祇树给孤独园。有一天佛陀告诉弟子们：“如果有人杀生害命，并且经常的这样去做，那么他将生在地狱之中；就算再世为人，他也会短命早死。

如果有人偷盗财物，并且经常的这样去做，那么他将生在地狱之中；就算再世为人，他也会贫困潦倒。

如果有人与他人通奸，并且经常的这样去做，那么他将生在地狱之中；就算再世为人，别人也会想办法与他的家人（妻子或丈夫）通奸。

如果有人说假话，并且经常的这样去做，那么他将生在地狱之中；就算再世为人，他也会被别人嘲笑讽刺、不信任。

如果有人挑拨离间，并且经常的这样去做，那么他将生在地狱之中；就算再世为人，他的家人朋友也会抵触、背离他。

如果有人口出恶语毁谤非议他人，并且经常的这样去做，那么他将生在地狱之中；就算再世为人，他也会被别人恶毒谩骂，他也会经常的听见恶毒诽谤的言语。

如果有人说不正经淫秽的话，说戏谑逗趣的话，并且经常的这样去做，那么他将生在地狱之中；就算再世为人，他说的话也没有人相信和采用。

如果有人贪得无厌，并且经常的这样去做，那么他将生在地狱之中；就算再世为人也会增长他的贪欲，让他再次堕落恶道。

如果有人愤怒怨恨，并且经常的这样去做，那么他将生在地狱之中；就算再世为人也会增长他的愤怒怨恨，让他再次堕落恶道。

如果有人不信因果，并且经常的这样去做，那么他将生在地狱之中；就算再世为人也会增长他的愚昧无知，让他再次堕落恶道。

如果有人不杀生害命，并经常的这样去修行，去反覆的实践，那么他将生到天界成为天人；就算再世为人，他也会长命百岁。

如果有人不偷盗财物，并经常的这样去修行，去反覆的实践，那么他将生到天界成为天人；就算再世为人，他也会家财万贯。

如果有人不与别人通奸，并经常的这样去修行，去反覆的实践，那么他将生到天界成为天人；就算再世为人，他的家人（妻子或丈夫）也会忠贞不二。

如果有人不说假话，并经常的这样去修行，去反覆的实践，那么他将生到天界成为天人；就算再世为人，他也会受到别人的称赞、尊重、信任。

如果有人不挑拨离间，并经常的这样去修行，去反覆的实践，那么他将生到天界成为天人；就算再世为人，他的家人朋友也会与他和睦相处，和气致祥。

如果有人不口出恶语毁谤非议他人，并经常的这样去修行，去反覆的实践，那么他将生到天界成为天人；就算再世为人，他也会经常被别人赞美、歌颂，他也会经常听见称赞、赞誉的言语。

如果有人不说不正经淫秽的话，不说戏谑逗趣的话，并经常的这样去修行，去反覆的实践，那么他将生到天界成为天人；就算再世为人，他说的话别人也会相信和采用。

如果有人不贪得无厌，并经常的这样去修行，去反覆的实践，那么他将生到天界成为天人；就算再世为人也不会增长他的贪欲，并且还可以让他再次上生善道。

如果有人不愤怒怨恨，并经常的这样去修行，去反覆的实践，那么他将生到天界成为天人；就算再世为人也不会增长他的愤怒怨恨，并且还可以让他再次上生善道。

如果有人深信因果，并经常的这样去修行，去反覆的实践，那么他将生到天界成为天人；就算再世为人也不会增长他的愚昧无知，并且还可以让他再次上生善道。”

佛陀说法圆满，弟子们再次顶礼佛陀，都欢喜的按着佛陀的教法修行。
