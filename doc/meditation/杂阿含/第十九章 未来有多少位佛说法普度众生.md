# 第十九章 未来有多少位佛说法普度众生？

完全读懂杂阿含经

有个时候，佛陀住在舍卫国的祇树给孤独园，有一天，一位婆罗门来到佛陀的住所，顶礼佛陀后，问佛陀：“世尊，未来会有多少位佛出世说法普度众生？”

佛陀告诉婆罗门：“未来会有不计其数的佛会出世说法普度众生。”

这时，婆罗门心里想，未来会有数不胜数的佛会出世普度众生，我现在还不急，反正以后会有无数的佛会出来说法度众，我随时都可以找到一位佛，跟着他修行的。想到这里，婆罗门就再次顶礼佛陀，欢喜的离开了，在回去的路上，婆罗门边走边想，我刚才只问了世尊，未来有多少位佛会出世说法普度众生，还没有问世尊，过去有多少位佛出世说法普度众生呀，想到这里，婆罗门就原路返回，再次来到佛陀的住所，顶礼佛陀后，婆罗门问佛陀：“世尊，过去有多少位佛出世说法普度众生呢？”

佛陀告诉婆罗门：“过去也有不计其数的佛出世说法普度众生。”

这时，婆罗门想，过去也有不可胜数的佛出世说法普度众生，我都没有遇见他们，也没有亲近他们，没有听闻他们说法开启智慧、解脱生死。如果未来我还是无法遇见不计其数的佛，无法亲近他们，无法听闻他们说法开启智慧、解脱生死，我不是就要永远的在这个生死轮回的世间痛苦挣扎了吗！我还是立刻皈依现在这位佛吧，听闻这位佛说法，跟着这位佛修行，早一点清净自在，早一点解脱生死。

婆罗门想完后便合上双手，说到：“世尊，请您让我做您的弟子，我愿意出家跟随世尊修行。”

佛陀告诉婆罗门：“你如果愿意遵守如来制定的戒律，愿意按如来所说的教法修行，如来就接受你成为出家修行的弟子。”

婆罗门说：“世尊，我愿意遵守世尊制定的戒律，愿意按世尊所说的教法修行，世尊请让我皈依您，我愿意做世尊的出家弟子。”

这时，婆罗门就出家受具足戒，出家之后，他想：我之所以要出家跟随佛陀修行，是因为要解除身心的烦恼痛苦，清净无染，解脱生死，最后证得阿罗汉、菩萨、佛的果位。
