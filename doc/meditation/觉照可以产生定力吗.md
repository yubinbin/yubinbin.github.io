# 觉照可以产生定力吗？

**内观的觉知当然可以入定，觉性持续地生起以后就可以入定**。

首先你得知道什么叫内观。**有两种禅修方式：止禅和内观**，自然也会有相应的两种“定”。

这两种禅修方式的原理和**目的本质上是从不同角度把你从日常生活中基于“我”的广义贪嗔痴思维、喜怒哀乐等情绪里抽离出来**。

止禅的抽离方式是让你专注于一个无功利、不会引发你世俗性思考的目标物，所以观呼吸、观腹部起伏、念经、念佛都是止禅，当你越来越专注、乃至全部心思都放在某个既不让你欢喜也不让你忧的目标物（佛号、佛经、呼吸、腹部起伏等等）上时就可以入定，**但止禅是一种压制心念的行为，止禅的禅定只是一种枯寂的禅定**。练习止禅（当然不必非得追求入定）可以缓解和解除一些粗重的烦恼，对调节身心有帮助，甚至可以辅助治疗某些情绪病。

**内观的抽离方式是任凭各种情绪念头来去，但是不陷入到情绪和相关思维里，只是客观觉知情绪念头来来去去时的身心感受变化**。

假设自然状态下的“心”为0，当1生气、2忧伤、3疑惑等等情绪出现时，**要像客观观察一张电波图纸上的波动起伏那样，觉知出现1、2、3等等情绪现象时与0态不同的身心感受变化，然后让它们自然消失**。

内观显然比止禅难得多，人很难不被情绪念头牵着走，这是需要持续训练的。当你客观觉知身心感受的时间大于或远大于陷入到各种情绪念头里的时长，觉性就会越来越饱满。**而当某个时段，觉性在全然观照时 ，就可以入内观禅定了**，进而就可以体证名色，也就是分别名色，体验到名色的生灭现象，**这是证悟的第一步、也是关键一步，所以这种“定”才更有价值**。
同样，练习内观，不一定非得追求开悟，可以用来调节身心、提升境界和情商，尤其是针对性格上有突出或暂时性困惑较大（以致于生活中经常出现某类情绪问题）的状况有助益。
