# 第二百三十三章 由条件生起的法

完全读懂巴利文大藏经

相应部22相应21经/阿难经(蕴相应/蕴篇/修多罗)

有个时候，佛陀住在舍卫城的祇树林给孤独园，有一天，阿难尊者来到佛陀的住所，顶礼佛陀后，阿难尊者对佛陀说：“世尊，您曾经说灭尽、灭亡。世尊，世间什么法的灭没被称为「灭」呢？”

佛陀说：“阿难！物质事物、物质身体是随时在变化的，是无法永恒保持不变的，是无法永远存在的。物质事物、物质身体是被条件所支配的，是由条件而生起的，是会生起、存续、变化、衰败、灭亡的。物质事物、物质身体是灭尽法、消散法、消退法、灭法，所以物质事物、物质身体的灭没被称为「灭」。

阿难！同样的道理，感受、念想、行为、认识、分别、判断是随时在变化的，是无法永恒保持不变的，是无法永远存在的。感受、念想、行为、认识、分别、判断是被条件所支配的，是由条件而生起的，是会生起、存续、变化、衰败、灭亡的。感受、念想、行为、认识、分别、判断是灭尽法、消散法、消退法、灭法，所以感受、念想、行为、认识、分别、判断的灭没被称为「灭」。”

佛陀说法后，阿难尊者再次的顶礼佛陀，随喜赞叹佛陀说法的无量功德，并按着佛陀所说的法去修行。
