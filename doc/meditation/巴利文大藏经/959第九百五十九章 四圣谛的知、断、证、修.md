# 第九百五十九章 四圣谛的知、断、证、修

完全读懂巴利文大藏经

相应部56相应29经/应该被遍知经(谛相应/大篇/修多罗)

有个时候，佛陀住在舍卫城的祇树林给孤独园，有一天，佛陀对众多的出家人说：“比丘们（比丘解释：受持具足戒的男出家人；具足戒解释：受持如来制定的所有戒律，比丘受持二百五十戒），有四种圣谛，是哪四种圣谛呢？即是：苦圣谛、苦集圣谛、苦灭圣谛、灭苦之道圣谛，这四种圣谛（四圣谛解释，见第九百三十二章）。

比丘们，在这四种圣谛中，有应该被完全弄明白的圣谛，有断除、灭尽的圣谛，有应该被印证的圣谛，有应该去亲自实践修习的圣谛。

比丘们，什么是应该被完全弄明白的圣谛？苦圣谛就是应该被完全弄明白的圣谛（苦圣谛详细解释，见第九百三十二章）。

苦圣谛是什么呢？「出生在世间的众生是很痛苦的」这是苦圣谛的法义。

什么是断除、灭尽的圣谛？苦集圣谛就是断除、灭尽的圣谛。

什么是苦集圣谛呢？「痛苦的根源是贪爱」这是苦集圣谛的法义。

苦集圣谛中应该被彻底断除、灭尽的是贪爱。

什么是应该被印证的圣谛？苦灭圣谛就是应该被印证的圣谛。

什么是苦灭圣谛呢？「只有先灭除了贪爱才能灭除痛苦」这是苦灭圣谛的法义。

灭尽了一切的烦恼和痛苦就印证了苦灭圣谛。

什么是应该去亲自实践修习的圣谛呢？灭苦之道圣谛就是应该去亲自实践修习的圣谛。

什么是灭苦之道圣谛呢？「灭除痛苦的方法就是修习八正道（八正道解释，见第九百三十二章）」这是灭苦之道圣谛的法义。

亲自修习八正道，就是在实践修习灭苦之道圣谛。

比丘们，你们要彻底弄明白四圣谛的法义，你们要持之以恒、坚持不懈的去忆念、回想四圣谛，你们要按着道谛中灭尽苦的方法去修行（道谛中灭尽苦的方法解释，即是八正道；八正道解释，见第九百三十二章）。”

佛陀说法后，听法的出家弟子们都再次的顶礼佛陀，随喜赞叹佛陀说法的无量功德，他们都按着佛陀所说的法去修行。
