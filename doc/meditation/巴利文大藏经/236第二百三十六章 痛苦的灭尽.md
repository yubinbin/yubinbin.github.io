# 第二百三十六章 痛苦的灭尽

有个时候，佛陀住在舍卫城的祇树林给孤独园，有一天，佛陀对出家弟子们说：“比丘们（出家人）！不能证悟明白物质事物、物质身体、感受、念想、行为、认识、分别、判断；不能完全的理解和明白物质事物、物质身体、感受、念想、行为、认识、分别、判断（完全理解和明白物质事物、物质身体、感受、念想、行为、认识、分别、判断的解释，见第二百三十五章）；不能除灭对物质事物、物质身体、感受、念想、行为、认识、分别、判断的贪爱；不能除灭对物质事物、物质身体、感受、念想、行为、认识、分别、判断的执着和挂念；不能舍离断除物质事物、物质身体、感受、念想、行为、认识、分别、判断的束缚捆绑，那么就无法彻底灭尽痛苦。

比丘们！证悟明白物质事物、物质身体、感受、念想、行为、认识、分别、判断；完全的理解和明白物质事物、物质身体、感受、念想、行为、认识、分别、判断（完全理解和明白物质事物、物质身体、感受、念想、行为、认识、分别、判断的解释，见第二百三十五章）；除灭对物质事物、物质身体、感受、念想、行为、认识、分别、判断的贪爱；除灭对物质事物、物质身体、感受、念想、行为、认识、分别、判断的执着和挂念；舍离断除物质事物、物质身体、感受、念想、行为、认识、分别、判断的束缚捆绑，那么就能彻底灭尽痛苦。”

佛陀说法后，听法的出家弟子们都再次的顶礼佛陀，随喜赞叹佛陀说法的无量功德，他们都按着佛陀所说的法去修行。
