# 第八十九章 生死如同海平面的涨跌

完全读懂巴利文大藏经

相应部12相应69经/高涨经(因缘相应/因缘篇/修多罗)

有个时候，佛陀住在舍卫城的祇树林给孤独园。有一天，佛陀对出家弟子们说：“弟子们，如来现在用比喻来为你们解说缘起法（缘起法解释，见第四十八章、第四十九章），当大海涨潮，海平面上涨的时候，与大海相连、流通的大河的水平面也会上涨；当大河的水平面上涨的时候，与大河相连、流通的小河的水平面也会上涨；当小河的水平面上涨的时候，与小河相连、流通的大湖泊的水平面也会上涨；当大湖泊的水平面上涨的时候，与大湖泊相连、流通的小水池的水平面也会上涨。同样的道理，弟子们，当「无明」高涨的时候，就会让「行」也高涨；当「行」高涨的时候，就会让「识」也高涨；当「识」高涨的时候，就会让「名色」也高涨；当「名色」高涨的时候，就会让「六处」也高涨；当「六处」高涨的时候，就会让「触」也高涨；当「触」高涨的时候，就会让「受」也高涨；当「受」高涨的时候，就会让「爱」也高涨；当「爱」高涨的时候，就会让「取」也高涨；当「取」高涨的时候，就会让「有」也高涨；当「有」高涨的时候，就会让「生」也高涨；当「生」高涨的时候，就会让「老死」也高涨。

弟子们，当大海退潮，海平面下降的时候，与大海相连、流通的大河的水平面也会下降；当大河的水平面下降的时候，与大河相连、流通的小河的水平面也会下降；当小河的水平面下降的时候，与小河相连、流通的大湖泊的水平面也会下降；当大湖泊的水平面下降的时候，与大湖泊相连、流通的小水池的水平面也会下降。同样的道理，弟子们，当「无明」消退、灭尽的时候，就会让「行」也消退、灭尽；当「行」消退、灭尽的时候，就会让「识」也消退、灭尽；当「识」消退、灭尽的时候，就会让「名色」也消退、灭尽；当「名色」消退、灭尽的时候，就会让「六处」也消退、灭尽；当「六处」消退、灭尽的时候，就会让「触」也消退、灭尽；当「触」消退、灭尽的时候，就会让「受」也消退、灭尽；当「受」消退、灭尽的时候，就会让「爱」也消退、灭尽；当「爱」消退、灭尽的时候，就会让「取」也消退、灭尽；当「取」消退、灭尽的时候，就会让「有」也消退、灭尽；当「有」消退、灭尽的时候，就会让「生」也消退、灭尽；当「生」消退、灭尽的时候，就会让「老死」也消退、灭尽；”

佛陀说法后，听法的出家弟子们都再次的顶礼佛陀，随喜赞叹佛陀说法的无量功德，他们都按着佛陀所说的法去修行。
