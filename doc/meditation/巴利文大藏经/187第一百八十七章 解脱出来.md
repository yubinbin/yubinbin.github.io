# 第一百八十七章 解脱出来

完全读懂巴利文大藏经

相应部18相应2经/色经(罗侯罗相应/因缘篇/如来记说)

有个时候，佛陀住在舍卫城的祇树林给孤独园，有一天，罗侯罗尊者来到佛陀的住所，他顶礼佛陀后，就在一旁坐下，佛陀对罗侯罗尊者说：“罗侯罗！你是怎么想的？世间的物质事物，包括世间人的物质身体在内，是永恒存在的，永远保持不变的，还是随时在变化的，无法永恒存在，无法永远保持不变的？”

罗侯罗尊者回答：“世尊，世间的物质事物会出现、形成、发展、衰败、消失，世间人的物质身体会出生、成长、生病、衰老、死亡。世间的物质事物，包括世间人的物质身体在内，是随时都在变化的，是无法永恒存在的，是无法永远保持不变的。”

佛陀说：“罗侯罗！你是怎么想的，声音、气味、味道、触觉、环境感觉（冷热、舒适等等）、念想，是永恒存在的，永远保持不变的，还是随时在变化的，无法永恒存在，无法永远保持不变的？”

罗侯罗尊者回答：“世尊，声音、气味、味道、触觉、环境感觉（冷热、舒适等等）、念想会出现、存在、渐退、灭尽、消失。声音、气味、味道、触觉、环境感觉（冷热、舒适等等）、念想，是随时都在变化的，是无法永恒存在的，是无法永远保持不变的。”

佛陀说：“罗侯罗！已经受到如来教导的圣弟子们，他们将会逐渐的除灭对世间一切物质事物的贪欲，他们将会逐渐的除灭对一切声音、气味、味道、触觉、环境感觉、念想的贪欲。他们不会再执着和挂念世间一切的物质事物，不会再执着和挂念自己的物质身体，不会再执着和挂念一切的声音、气味、味道、触觉、环境感觉（冷热、舒适等等）、念想，他们从世间一切的物质事物中解脱出来，他们从一切的声音、气味、味道、触觉、环境感觉、念想中解脱出来，他们由此证悟了解脱的智慧，证悟了解脱的果位，他们彻底的明白：「从这一世开始已经不会再次的出生在世间。行为、言语、念想的修行已经圆满，应该做的事情已经做好，不会再有轮回的状态，不会再出生在世间了」。”

佛陀说法后，罗侯罗尊者再次的顶礼佛陀，他随喜赞叹佛陀说法的无量功德，并按着佛陀所说的法去修行。
