# 第二百四十二章 痛苦的根源

完全读懂巴利文大藏经

相应部22相应31经/痛苦之根经(蕴相应/蕴篇/修多罗)

有个时候，佛陀住在舍卫城的祇树林给孤独园，有一天，佛陀对出家弟子们说：“比丘们（出家人）！如来现在要教导你们：什么是痛苦？什么是痛苦产生的根源？你们要认真的听，你们要仔细的思考，如来要开始说法了。”

出家弟子们回答：“世尊，我们会认真听您说法的，我们会仔细的思考的，恭请世尊您为他们说法。”

佛陀说：“比丘们！什么是痛苦呢？物质事物、物质身体就是痛苦，感受、念想、行为、认识、分别、判断就是痛苦。什么是痛苦产生的根源呢？就是对物质事物、物质身体、感受、念想、行为、认识、分别、判断生起快乐、喜悦。对物质事物、物质身体、感受、念想、行为、认识、分别、判断生起贪欲、渴爱，也就是：生起对欲望的渴爱，生起对存在、生存、获得的渴爱，生起对永远解脱生死的渴爱，生起对不生不灭涅槃境界的渴爱，比丘们！这就是痛苦产生的根源。”

佛陀说法后，听法的出家弟子们都再次的顶礼佛陀，随喜赞叹佛陀说法的无量功德，他们都按着佛陀所说的法去修行。
