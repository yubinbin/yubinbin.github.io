# 第一百九十四章 从界中解脱出来

完全读懂巴利文大藏经

相应部18相应9经/界经(罗侯罗相应/因缘篇/如来记说)

有个时候，佛陀住在舍卫城的祇树林给孤独园，有一天，罗侯罗尊者来到佛陀的住所，他顶礼佛陀后，就在一旁坐下，佛陀对罗侯罗尊者说：“罗侯罗！你是怎么想的？地界（地界解释，见第一百二十四章）是永恒存在的，永远保持不变的，还是随时在变化的，无法永恒存在，无法永远保持不变的？

罗侯罗尊者回答：“世尊，地界是随时都在变化的，是无法永恒存在的，是无法永远保持不变的。”

佛陀说：“罗侯罗！水界、火界、风界（水界、火界、风界解释，见第一百二十四章）、空界、识界是永恒存在的，永远保持不变的，还是随时在变化的，无法永恒存在，无法永远保持不变的？

罗侯罗！什么是空界呢？就是能够容纳物质事物的空间、虚空，比如孔洞、裂缝、空地、口腔、咽喉、肚肠等等。

什么是识界呢？就是眼识、耳识、鼻识、舌识、身识、意识（眼识、耳识、鼻识、舌识、身识、意识解释，见第一百八十八章）。

罗侯罗尊者回答：“世尊，水界、火界、风界、空界、识界是随时都在变化的，是无法永恒存在的，是无法永远保持不变的。”

佛陀说：“罗侯罗！已经受到如来教导的圣弟子们，他们将会逐渐的除灭对地界、水界、火界、风界、空界、识界的贪欲，他们不会再执着和挂念地界、水界、火界、风界、空界、识界，他们从地界、水界、火界、风界、空界、识界中解脱出来，他们由此证悟了解脱的智慧，证悟了解脱的果位，他们彻底的明白：「从这一世开始已经不会再次的出生在世间。行为、言语、念想的修行已经圆满，应该做的事情已经做好，不会再有轮回的状态，不会再出生在世间了」。”

佛陀说法后，罗侯罗尊者再次的顶礼佛陀，他随喜赞叹佛陀说法的无量功德，并按着佛陀所说的法去修行。
