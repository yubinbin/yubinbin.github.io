# 第九十三章 茅草上的水多吗？

完全读懂巴利文大藏经

相应部13相应2经/莲花池经(现观相应/因缘篇/如来记说)

有个时候，佛陀住在舍卫城的祇树林给孤独园。有一天，佛陀对出家弟子们说：“弟子们，如果有一个长2000里，宽2000里，深2000里的莲花池，并且这个莲花池充满了水，周边的飞禽走兽都能喝到莲花池里面的水。如果有一个男子他把一束茅草放入莲花池的水中又拿起来，弟子们，你们想想看，茅草上面附着的水与莲花池里面的水相比，那个的水更多？”

出家弟子们回答：“世尊，这是很明显的事情嘛，肯定是莲花池里面的水更多，茅草上面附着的水更少哦，茅草上的水实在是比不上莲花池里面水的百分之一、千分之一、十万分之一，茅草上的水与莲花池里面的水相比可以忽略不计。

佛陀说：“同样的道理，弟子们，具足正确见解，已经证悟初果（初果解释，见第七十章）及以上果位的圣弟子们，他们灭尽、灭除的烦恼和痛苦很多，他们灭尽的烦恼和痛苦就如同莲花池里面所有的水那样多，他们残留的烦恼和痛苦非常的少，他们残留的烦恼和痛苦就如同茅草上附着的水那样少。弟子们，也就是说已经证悟初果的圣弟子们，他们残留的烦恼和痛苦比不上他们灭尽烦恼和痛苦的百分之一、千分之一、十万分之一，他们残留的烦恼和痛苦与他们灭尽的烦恼和痛苦相比可以忽略不计。这些已经证悟初果的圣弟子们，他们最多在人间和天界往返七次，就能永远的从生死轮回中解脱出来，也就是说已经证悟初果的圣弟子们，他们最多再有七次的生死轮回，就能除灭一切的烦恼和痛苦，就能从这个世间永远的解脱出来，就能从生死轮回中永远的解脱出来。弟子们，具足正确的见解，证悟初果就能获得这么大的功德利益，明白了如来所说的正法，就能获得这么大的功德利益。”

佛陀说法后，听法的出家弟子们都再次的顶礼佛陀，随喜赞叹佛陀说法的无量功德，他们都按着佛陀所说的法去修行。
