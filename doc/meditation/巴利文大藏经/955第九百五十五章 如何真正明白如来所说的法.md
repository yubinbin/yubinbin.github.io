# 第九百五十五章 如何真正明白如来所说的法

完全读懂巴利文大藏经

相应部56相应25经/漏的灭尽经(谛相应/大篇/修多罗)

有个时候，佛陀住在舍卫城的祇树林给孤独园，有一天，佛陀对出家弟子们说：“比丘们（比丘解释：受持具足戒的男出家人；具足戒解释：受持如来制定的所有戒律，比丘受持二百五十戒），如来说：灭尽了一切烦恼和痛苦的修行者，他们才是真正知道如来所说善法、正法、解脱法的圣者，他们才是真正彻底明白了如来所说善法、正法、解脱法的圣者。

比丘们，如何才能灭尽一切的烦恼和痛苦呢？那就要知道和明白四圣谛的法义（四圣谛解释，见第九百三十二章），那就要知道和明白：

「出生在世间的众生是很痛苦的」这是苦谛的法义；

「痛苦的根源是贪爱」这是集谛的法义；

「只有先灭除了贪爱才能灭除痛苦」这是灭谛的法义；

「灭除痛苦的方法就是修习八正道（八正道解释，见第九百三十二章）」这是道谛的法义。

比丘们，在初步知道和明白了四圣谛的法义后，就要持之以恒、坚持不懈的去修习八正道。当修习八正道灭尽了一切的贪欲、渴爱后，当修习八正道灭尽了一切的烦恼和痛苦后，就能通过自己的修行印证四圣谛所显现出来的法义，就能彻底完全的弄明白四圣谛的法义，这时就证悟了阿罗汉果位，这时就证悟了无上正等正觉，这时就进入了没有烦恼，没有痛苦，没有执着，没有挂念，没有念想的涅槃境界（八正道解释，见第九百三十二章；阿罗汉果位解释，见第七百九十二章；无上正等正觉解释：已经完全证悟明白世间一切的真相、真谛，并由此开启了圆满的智慧，从世间彻底的解脱出来）。

比丘们，当知道和明白了四圣谛的法义，当亲自持之以恒、坚持不懈的去修习八正道印证了四圣谛所显现出来的法义，就能灭尽一切的贪欲、渴爱，就能灭尽一切的烦恼和痛苦，证悟解脱的果位，到达涅槃的彼岸。

比丘们，你们要彻底弄明白四圣谛的法义，你们要持之以恒、坚持不懈的去忆念、回想四圣谛，你们要按着道谛中灭尽苦的方法去修行（道谛中灭尽苦的方法解释，即是八正道；八正道解释，见第九百三十二章）。”

佛陀说法后，听法的出家弟子们都再次的顶礼佛陀，随喜赞叹佛陀说法的无量功德，他们都按着佛陀所说的法去修行。
