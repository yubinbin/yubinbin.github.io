# 第二十三章 生起哪三种念想会烦恼痛苦？

完全读懂巴利文大藏经

相应部3相应23经/世间经(憍萨罗相应/有偈篇/祇夜)

有个时候，骄萨罗国的波斯匿王来到佛陀的住所，他顶礼佛陀后在一旁坐下，波斯匿王对佛陀说：“世尊，当内心生起什么念想的时候，就会让自己烦恼痛苦、无法安宁？”

佛陀说：“大王，当内心生起贪欲念想的时候，就会让自己烦恼痛苦、无法安宁；当内心生起愤怒念想的时候，就会让自己烦恼痛苦、无法安宁；当内心不明因果、没有智慧生起愚痴念想的时候，就会让自己烦恼痛苦、无法安宁。

大王，当内心生起这三种念想的时候，就会让自己烦恼痛苦、无法安宁。

内心生起贪欲、愤怒、愚痴念想的人，他们伤害别人的同时也会伤害到他们自己。就如同长满果实的树木，被很多人争相折枝采摘果实。树枝被众人折断，果树受到伤害的同时，这些人也会为果实互相争斗而受到伤害。”

这时，佛陀说偈言：

「 贪嗔以及痴，此恶心生人。

   害人如害己，如争树果实。

   折枝又互斗，树损人亦伤。」
