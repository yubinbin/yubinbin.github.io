# 第二百三十一章 没有永恒的快乐

完全读懂巴利文大藏经

相应部22相应19经/有因的苦经(蕴相应/蕴篇/修多罗)

有个时候，佛陀住在舍卫城的祇树林给孤独园，有一天，佛陀对出家弟子们说：“比丘们（出家人），世间人的物质身体会生病、衰老、死亡，世间人无法青春永驻，无法永远不死；世间人会失去自己拥有的物质事物，世间人拥有的物质事物会衰败、灭亡、消失，世间人无法永远的拥有物质事物，既然如此，那么物质身体、物质事物最终给世间人带来的都是痛苦。比丘们！就连形成、生起物质身体、物质事物的起因、条件都是最终给世间人带来痛苦的，世间哪里有永远带来快乐的物质事物、物质身体呢？世间哪里有永恒的快乐呢？

比丘们（出家人），同样的道理，世间人的感受、念想、行为、认识、分别、判断会让他们不满意、不快乐、不开心，世间人的感受、念想、行为、认识、分别、判断无法永远让他们满意、快乐、开心。世间人会失去让他们满意、快乐、开心的感受、念想、行为、认识、分别、判断。世间人的感受、念想、行为、认识、分别、判断会消退、灭尽。既然如此，那么感受、念想、行为、认识、分别、判断最终给世间人带来的都是痛苦。比丘们！就连形成、生起感受、念想、行为、认识、分别、判断的起因、条件都是最终给世间人带来痛苦的，世间哪里有永远带来快乐的感受、念想、行为、认识、分别、判断呢？世间哪里有永恒的快乐呢？

比丘们！当你们有了这个正确的见解，那就是已经受到了如来的教导。已经受到如来教导的圣弟子们，他们不会执着和挂念物质事物、物质身体、感受、念想、行为、认识、分别、判断，当他们不执着和挂念这些事物的时候，就不会被这些事物束缚捆绑，就不会因为这些事物胡思乱想、胡作非为，就不会让这些事物污染自己内心清净的境界。当他们彻底从这些事物中解脱出来的时候，彻底的灭尽一切烦恼和痛苦的时候，他们就开启了解脱的智慧，他们就证悟了解脱的果位，他们自己就明白了：「从这一世开始已经不会再出生在世间了。行为、言语、念想的修行已经圆满，应该做的事情已经做好，不会再有喜怒哀乐等等烦恼和痛苦的轮回状态了，不会再出生在世间了，已经彻底从生死轮回中解脱出来。」”

佛陀说法后，听法的出家弟子们都再次的顶礼佛陀，随喜赞叹佛陀说法的无量功德，他们都按着佛陀所说的法去修行。
