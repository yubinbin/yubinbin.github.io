# 如何检验一个开悟者，或检验自己是否已开悟？

第一步的标准就是名色分别、分离蕴呗。
没有烦恼，不是说一种包容、达观心态主导一切，不是心变成石头了，更不是有些北传“高僧”们说的“一切都是假的”。
烦恼是什么？喜怒哀乐各种心态情绪是广义烦恼，负面情绪就是狭义烦恼。
那么没有烦恼的极致是什么？俗话说“青春痘长在别人脸上不让你担心”。你自己的烦恼再小再少那也是烦恼，而对于别人的烦恼你则只是旁观者。

而名色分别就是让你成为自己的烦恼（喜怒哀乐）的旁观者，真实感受到你的“心”与心里的“喜怒哀乐”是分开的，不是你在喜怒哀乐，而是喜怒哀乐自己在喜怒哀乐。因为喜怒哀乐对于你的“心”来说只是客人，来了又走，走了又来，来来去去，“今天哭，明天笑，不求有人能明了”。

这个道理好像人人都懂，但那是偶尔的回望式总结，**只有通过持续如链地如实观照、也就是及时客观觉知喜怒哀乐的来去现象，最终才会实现名色分别，这就是证悟流程的第一步**。

人人也可以随时随地运用如实观照（客观觉知当下身心现象）这种方法减少压缩狭义烦恼，调节身心。
