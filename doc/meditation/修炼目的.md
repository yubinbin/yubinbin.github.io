# 总是容易被他人情绪所影响该如何办？

多内观吧，定力不够，觉知不够，因此后知后觉。

观照自己的起心动念，念头一动，情绪就波动，如果观照不够，情绪的波浪不断生长，等你意识到的时候，已经被外界的人或者事所束缚，此时已经心有所执，执妄为实。

观照的力量有了之后，念头一动就知道，知道的同时就放下，放下的时候就空掉，观照再敏锐的，念头还没等动，已经空掉了，情绪的通道根本来不及造作，这就是上工治未病。

再好一点的，知道一切本来虚幻，入淤泥和六尘也无碍本心，

所以一开始修行要出离，闭关，因为定力不够，要专修，有了定力要检验，专门历事炼心，看看自己是心能转物，还是物能转心。

定力不够的主动退，这叫长养圣胎，其实就是保护真心，定力有了，也要慢慢历练，不可托大。所以说，一开始是不可进寸而退迟 ，这就是火候。

一直闭关的也要主动出观，闭关就是为了出观，只闭不出是自说自话，遇到境界能不能如如不动，能够如如不动这是真闭关。

修行不是逃避，修行是更大的担当，不怕被恶名，不怕被冤枉，不怕被误解，不去求贤名，为了名而逃避，这就是落圣，执凡执圣都是偏颇。虽说担当也是空话，不可执着，自然而然，担与不担都不碍本心。

老子说和光同尘就是百千亿化身，无所不包，无所不容，随众生心显化一切相，而不是让众生心随我之心，很多人这里总喜欢弄返，以我所谓圣知圣见要求别人，这就是颠倒，不是应缘显现，而是以执妄生事断。
