# 佛家最经典的书是《金刚经》吗？

**佛家所有的经典，全是指月之手，渡河之舟，也就是指向开悟的工具。**

**儒释道经典皆然。**

**全看求道者的因缘在哪里，与哪个经典相印。**

**金刚经，直接讲月亮，心经也是。**

**一旦开悟，你会明白一切文字都是多余的。**

**因为文字无法描述那无法描述的，是徒劳的。**

**就像解释给古代人巧克力是什么东西。**

**唯有掏出一块，送进那人口中，待他细嚼慢咽品尝完毕，他才明白巧克力是啥。**

**吃完后，他再听你之前解释给他听的，他就能听懂了，然而对他来说，这个解释（一切经典）已经是多余的，可以扔了。**
