# 修行就是修心吗?

修行之根，先识本心，不识本心，学法无益。

本心本自清净。那为什么还要修？修的是习气。

不是修静，不是找静，是本自清净，本自具足。

只是习气容易迷在境上，被五欲六尘遮住真心道体。

念头容易攀缘，流连忘返，就是人人本自道成，家里都很富足，觉得自己道贫，其实身贫道不贫。

所以要不随念转，念头是真如之妙用。该用则用，用过放下，不执着，回归真如之体。

老子说如刍狗，刍狗就是该用就用，用过就放下了。用就是无不为，心不染着就是清净无为。

所以用不离体，体不离用。用而不迷，不迷而用，体用一如。

修什么习气？修不着相的习气，凡所有相皆是虚妄。是生灭的，变化的，无常的，缘起缘灭的。了不可得，但是我们会被相所欺，住相牵挂，心有挂碍，就有颠倒梦醒，以幻为实。

所以要时刻归根，心是根，念是用。用不离根，根不离用，活泼自在，顺逆无拘。

念起即觉，觉即化空。念起时妙用，妙用不离本觉，觉了后觉也不可得，觉也化空。空自本空，能生妙有。所以是无中生大有，是性空妙有。

易经说寂然不动感而虽通天下之故，自然而然。

寂然不动为真如，感而随通为妙用。随缘而应，自自然然。有如空镜，胡来现胡，汉来显汉。

物来触我，我不触物。随缘在行住坐卧中，妙用识心，妙用在于明白一切都是虚幻，是生灭之念，是缘起缘灭，真空妙有。

心地虚明，无凡无圣，无相无貌，显时则用，隐时则寂。说空它非空，说有它非有。

道本圆成俱足，无修无得无证，如何不得而得？时刻认祖归宗！
