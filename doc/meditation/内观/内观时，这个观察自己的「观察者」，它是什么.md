# 内观时，这个观察自己的「观察者」，它是什么？

它是一种纯然的意识状态吗？ 还是我们锻炼培养出来的？ 它会不会判断思考？

问题就出在“观察者”这个提法上。“观察”，普通人都会想是“用眼睛看”，或者引申出来，用脑子看，接着就是脑子判断，用脑子分析……

**这就跑偏了！其实观察并不只是用眼睛，或者用脑子**。

**内观其实是用全身感知的过程，得用上五感，至少你得用上听觉和感觉。不止是听明显的声音，而且要听四面八方的声音，感全身各处的感受**。

“观察自己”的这个提法，里面有：我，观察，自己。我和自己是分裂的。

**内观或者任何冥想类的修行方法，是往“合一”的方向修。**

注意力不是在一个点上，而是四面八方，无处不在。于是“我”和“自己”就合一了。

我觉得用“感”，比用“观”，更少造成误解。

感一切当下所感，不判断，不思考，当下有什么，就感什么
