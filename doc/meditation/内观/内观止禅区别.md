# 内观？正念冥想？其实很可能你除了“想”，啥都不会

&emsp;&emsp; 多数人都是如此，即便很多号称学习佛理、践行正念冥想的人，啰哩啰嗦分享了一大堆，**其实还是只会去想、去思维。禅修的止禅和内观，恰恰都不是思维。这两种方法的目的就是稀释冲淡你的惯性思维和情绪**，你所有的思前想后、喜怒哀乐全是围绕着“我”，但是“为我”的具体表现却又都是“心往外送”的行为。

 就算思维正能量、仰慕修心，又哪怕是喜乐通透的各种美好情绪，又或者空谈佛理，更别说靠“极乐世界”这类理念支撑的信念了，这些都没有本质区别，全是“心往外送”的表现。现如今，除了几乎不存在的“利根之人”，**你最好老老实实地实践止禅和内观这两种不属于思维的操作方法**，**它们专门对治“心往外送”**。

**止禅的目的是“归一”**，姑且“心往外送”吧，但是让你把“心”送到一个单一的无世俗意义的目标物（佛号、佛经、呼吸、腹部起伏）上，所以念经、念佛、观呼吸、观腹部起伏、甚至观水泥柱子、数羊………，这些都是止禅。

**内观，则是回归身心本来面目的活动，也就是培养或照见传说中的、本自具足的“菩提自性”、“觉性”**。以下两图（内容出自南传禅修证悟之人的分享）简洁透彻地说明了内观的目标物和操作方法问题，可仔细琢磨、践行。

内观（Vipassana，毗婆舍那）

下面的图1说的是内观的目标物问题。**当然这是就内观的“观心”而言。这段话可以帮助我们明确目标。内观关键要知道“观”的目标是什么**？文中的例子是一个外在的声音引起了你的某种感受，这个例子其实可以“以小见大”地反映我们日常生活的方方面面。**“内观”要去“观”或者说觉知的就是这个（由于某些或明或暗外因引发的）感受，而不要去管外因**。 我们的困难在于，出现由于某种外因而产生的感受之后，通常会立即：

1. 条件反射式地陷入到相关的情绪反应里，单就负面情绪而言，要么烦躁要么生气等等，以及陷入到对引起这些感受的外因、外境的态度里。
2. 自以为高明一些的人，由于平时阅读心灵鸡汤、文史哲甚至佛学读物或者以往相关经验的积累，幡然醒悟，觉得不应该这样受外境影响，应该有修养，而且这正是“事上修”的好契机嘛，经过这一番思忖，就开始对治负面情绪。

这两点其实没有本质区别，**都属于对情绪感受的习性反应，也还是“心往外送”**。

第②点虽然可以说是后天努力上进培养的结果，但依然是思维，不是内观。

**内观的目标物只是身心感受变化本身，不管是什么外境外因（涵盖万有）造成的，反正你的身心起了一个变化**。

***内观的目标物就是这个新出现的变化本身，不管是严重的、容易感知的（比如生气时的颤抖，血液流动加速）还是轻微的不满意心态，努力去觉知它，既不要迷失在其中，也不要用思维对治它***。

**练习内观，就是要让我们从以往想当然地“因为A（外因），所以我B（感受）”的思维逻辑或习性反应里跳出来**。

图2说的是如何去“观”或觉知。文中第二段有一个很精妙的比喻例子，

**就像迎面吹来一阵风，风吹拂你的身体的时候，你的身心就会出现一种新的感觉变化啊，觉知无风到有风的变化，然后让风自然地消失离开。这就是内观**。
