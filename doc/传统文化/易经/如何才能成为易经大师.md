# 如何才能成为易经大师?

《周易》原来很简单。

《易》通过八卦（天-乾、地-坤、水-坎、火-离、山-艮、雷-震、风-巽、泽-兑）的两两组合成一幅幅形势图（六十四卦），并指明了各种形势下可能发生的情况及正确或错误的对策。

《周易》原来并不难。

如何才能在三个月内理解《周易》呢？从它的本意＂治国之道＂出发。《周易》是一本讲述治国之道的书。它的主要内容为：总纲、培养继承人、治国篇、兴国篇、国战篇，整整64卦论述了国家兴盛—衰落—覆灭—兴起—强大—对抗—一统的详细过程，并就各时段的具体情况提出了相应的对策。而这整个过程就是国家的发展规律。

按照这个思路，一个月基本能明白整本《周易》的意思了。再用一个月的时间联系历史上各朝代的兴衰过程，把每一卦的意思放在相应的时段中分析，你就能掌握＂治国之道＂。最后，把＂治国之道＂转化为＂人生之道＂，用《周易》去分析生活中的事件，一个月时间够了。

《周易》用起来很方便。

就是说，明白《易》各卦的意思后，把当前的人或物所处的情况代入相应的形势图，就可以推算出人物、事情的发展以及采用的对策是否正确。

例如一家公司受到竞争对手的全力打压，处境艰难。应该怎么办呢？请查看《易》——如果竞争对手的实力远在本方之上，当参照第五十二卦“艮卦”；如果竞争对手的实力和本方相当，应参照第五十五卦“丰卦”。

又如在胜利即将来临的时候应该注意什么呢？如果是在对抗中取得的胜利，请参照第六十三卦“既济卦”；如果是胜利地接班，请参照第十一卦“泰卦”。

还有，某人要追女朋友，《易》有没有方法指导？当然有！如果两人刚刚认识，应参照第31咸卦-37家人卦，有针对性地建立好感；然后参照第38睽卦-45萃卦，积聚联合内外各方助力；最后在适当时候参照第46升卦-50鼎卦，时机已至，发起冲刺，把她抱回家。

这就是《易》的第二个原则“简易”：从最根本的道理——“易”与“不易”出发，把复杂的人物、事件、道理，变得非常简化。简化到什么地步？按图索骥的地步。

这样，你也能成为《易》学大师。
