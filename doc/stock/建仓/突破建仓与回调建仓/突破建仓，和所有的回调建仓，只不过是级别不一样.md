# 突破建仓和回调建仓其实都是一样的！！！

这个可能你无法接受，可是事实就是这样的！

市场是突破一个价格，就反转，或者延续，除非有更大的力量，导致市场再次转向，如果没有，就会一直延续这个方向的，包括“假突破”

所有的突破建仓，和所有的回调建仓，只不过是级别不一样而已，并没有其他，当然你如果把突破建仓定义成为，突破某一个区间得最高点，叫做突破建仓，你无法理解我说的，你也会用“假突破”来反驳我，可是那个真不是突破建仓。

所有的突破建仓，必须是建立在，反向趋势运行结束后，出现的关键价格出现，被突破，这时候建仓，才叫突破建仓！

这里真的没有假突破，看起来就是在区间里面的胡乱开仓，可是事实上则是，市场突破了，区间得关键点，并且，确定了，反向趋势得结束，以及操作趋势开始得时候，也就是说，你在开仓的时候，就已经是顺势的了，并且一定是趋势刚刚开始的时候，当然这时候会有加仓的需求，加仓的原理，不过就是不同价格级别，完成收割，并且反向次要波动结束，再次进入主要波动的时候，才是你加仓得时候，这个和以上确认是完全一样的，没啥不同！

再说一下回调建仓，所有的回调建仓，只不过是在假设反向趋势结束的时候建仓，可是你要知道，行情是从小级别向大级别传导，大级别反过来又制约小级别的过程，你所谓的得回调建仓，一定就是小级别反向趋势结束的时候，和以上的突破建仓没啥区别，如果非要找茬，那么就是级别大小不同的关系，当然还有就是趋势形成以后的回调建仓，这个则是在趋势运行过程中，找出来关键点进行建仓，这个是比较繁琐一点的，因为市场在趋势运行过程中，判定趋势是不是正常发展的，是需要几个价格，这些价格看起来并不关键，但是一旦破掉这些价格，都必然是代表了趋势得延续和反转，这个判定，并不是所谓的趋势线或者均线回踩得价格，这点是尤为要注意的！

我不知，我说的你是不是能够理解，概括一下就是，首先定义突破，突破并不是你在盘面中看到的，那些区间高低点的突破，回调也是对反向趋势而言。其次是找出来他们，如果他们被破，那么需要知道会引起哪个关联级别得波动（这个波动决定了肉的大小，这样你就不会迷路了），然后根据自己适合的初损来搞，再结合动损和资仓管，做好防护以及加减仓，搞进去就可以，最后就是跟踪健康的趋势，不断的低买高卖，就可以了！

交易里面最重要的是，学会做多让空，做空让多，价格是运动的，必须学会找到正常以及失常，然后再去判定和发现市场的关键价格，等到价格一旦突破这些关键价格，就搞进去，一击不中，马上遁走，等待下次机会就好，突破也好，回调也罢，真的无所谓的，市场是具备自相似的特征得，所以才会这样！
