# 为什么说交易系统越简单越好？

因为交易是搞应对而不是搞预测。

如果我俩猜拳，在不考虑规则的情况下，怎么样你才能赢的最简单，那就是你比我慢一步，我出拳头，你就出布，我出布，你就出剪刀。那怎么样你才会赢的最艰难呢，那就是你比我快一拍，你先出我后出，这时候你不得不去预测我会出什么，但事实是你永远先出，所以你大概率会输。

对于猜拳来说，规则已经定死了，所以你先出和后出都是不可以的。但是对于交易来说，没人拿刀逼着你先出牌，所以，交易怎么样赢的最轻松，你让市场先出牌，不要去猜测市场会怎么，市场走出来什么样就是什么样，你等他走出来之后再动手，不就简单了么。

为啥有些人会把交易系统搞得很复杂呢，原因是他们总想预测市场，总想先于市场一步，但是他们忘记了一点，市场并不是你一个人在交易，你认为的好不叫好，大家都认为的好才叫好。墙倒众人推，做交易，不是要你去找一个墙去推推看他会不会倒，而是要去找一个已经快要被大家推倒的墙你跟着大家一块推。交易又叫投机，投机就是耍滑头，那就好好的把滑头耍好就行了。

市场要随机应变
所以，一旦起了先于市场出牌的念头，交易就会变得无比的复杂，你会不停的去找各种因素，一个技术指标叠加一个技术指标，这样优化又那样优化，最后发现还是不行，因为市场本来就不可以被预测，你在尝试解决一个不可能的事情，你说答案会有多复杂呢？

交易系统要的是应对之策，如果市场出a，我就出b，如果市场出c，我就出d，如果市场耍赖，他出了a然后他又偷牌把a撤了换成c，那我也耍赖，我偷牌也把b撤了换成d。交易者在市场中就要像水一样，市场是瓶子，交易者就变成瓶子，市场是袋子，交易者就变成袋子，永远跟进市场，紧贴市场，而非预测市场，强迫市场。

这样，你的交易系统自然就简单了下来。
