# 你是根据预测行情来进行开仓的吗？

不预测。只跟随。

预测没有意义。

你预测多，行情多，你做多。这种是最爽的，你预测对了。

你预测多，行情空，你做多。

你亏了。

你预测多，行情多，你没做。在那马后炮，早知道就买了。

你预测多，行情空，你没做。

你说，幸好没做。

上面就是一件事情的完全分类。你发现了什么嘛？

你的预测没有意义。。。

大部分人会钻到第一条去，去增加自己的预测正确的几率。

那就是从一个坑跳到一个更大的坑去了。

做交易最重要的就是两句话。

你做对了你赚了多少钱？

你做错了又亏了多少钱？。

闭着眼睛买入后（不考虑加仓）。你只剩下一个操作那就是卖出。

卖出只有两种情况

亏损的卖出

盈利的卖出。

亏损的情况就转止损系统

盈利的情况就转止盈系统。
