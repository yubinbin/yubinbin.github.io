# 做交易，怎么才能不执着于技术？

取舍有度

交易的本质就是数学逻辑......
交易真的不适合大多数人！

为啥呢？

得失心太重了！

就这一个原因！

得，指的是贪婪；

失，指的是恐惧；

心，指的是人性！

给你一套可以盈利的系统，你也有90%的可能失败！原因就是这个得失心太重！

例子呢，太多，我这里就讲一个:

耐心的等待你看的懂且有把握的机会再出手！就这一个要求，有几人能做到？

做不到有这几个原因：

第一，你根本就没有看的懂的行情；

第二，你根本就没耐心去等待；

第三，你总喜欢把系统不断的改来改去！

重点就这三个！

第一个问题属于技术问题，这个也是最好解决的问题，一条均线，或一条趋势线就能解决了，技术问题是交易中最简单的问题！比如，顺着一条均线的方向，就能有胜率很高的进出方法！

第二个问题，是最难的问题，目前我只能说，只有增加认知来解决，其它我没有什么好的建议。

第三个问题，属于耍小聪明，有了系统就不能随意改动，即便是要改动，也是需要长期的实战沉淀后的事，每改动一次，就相当于重新建立了一次系统！也属于认知问题。

我最后想说，交易的技术很简单，所有那些复杂技术的背后，无不是充满了欺骗与误导的目的！我还是那句话，对于新手来说，找条均线跟随做单，就是一个最牛逼的交易方法！

世界上也没有比用均线指导你操作还正确的方法了！

虽然均线是滞后的！但那个技术体系不是滞后的呢？不滞后，又怎么会看出趋势方向呢？顺势跟随交易，就是让你滞后交易的呀！
