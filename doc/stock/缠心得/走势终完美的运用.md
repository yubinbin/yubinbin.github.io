# 走势终完美的运用

走势终完美告诉我们：

一、从价格出中枢的那一刻起，就不能再追了。因为价格已经进入一类买卖点区域，随时可以终完美。此后，顺势单唯一的机会，就是离开中枢比较远，走次级别回调或反弹不回中枢内部的三类买卖点。由于三类买卖点只有一个，因此顺势单的机会就只有一次。而且，三类买卖点还未必一定成功，它可能直接失败，也可能走三买转二卖，还有可能走小转大。

二、走势类型到底什么时候会完美，会以什么方式去完美，我们没必要去分析、预测、猜测，而只需要等待，只需要看，看什么？看它有没有走势类型结束的特征。

三、走势终完美不是操作的逻辑，走势终完美之后的完全分类才是操作的逻辑，有完全分类才能实现不测而测，有完全分类才会有完全应对的策略。

四、做交易，做的是未来。走势终完美告诉我们，不能看到什么才去做什么，而是应该看到单边准备做震荡，看到震荡准备做单边。

五、一个走势类型会以怎样的方式去完美，一定是有特征的。目前为止已发现的特征有两个：
一是由小到大的背驰；二是区间套之中枢越来越小。
