
# 缠论的买卖点，绝对不可以也没可能百分之百的把握，只能概率和试错。

禅师在前面课程中讲得很清楚：1买不可靠，2买较可靠。其实缠师是说了要止损的，只是说得不够明白，你可以再读原文。

前期缠中说禅课程已比较客观，后面就狂妄了，号称几何化了，百分之百保证了。这只是缠中说禅想激发你的贪嗔痴疑慢，“棒喝”你，这点缠中说禅说过。

其实，缠论买卖点，一定是走出来了才确定，就是3买成立，则1买成立，否则1买只是概率买点，当下只是假设点而已，会出现若干符合缠中说禅判断条件的1买，其实缠中说禅又何尝准确定义过准确的1买，只是附有假设条件的1买，相对的含有未来函数的1买，就是“最后一吻”后的买点或者“最后一个中枢”后的背驰，这“最后”就是未来函数，要未来成立了，这“最后”才成立，3买成立以后，前假定的1买才成为真正的1买。1卖也这样。1类买卖点都这样了，依赖于1买为前提条件的2类买卖点当然也是这样，3类买卖点当然也是这样。缠中说禅玩庄家就是3买介入，然后玩死你。这在说玩庄家的课程中就说过。

**缠中说禅买卖点的确定性，缠中说禅说明了那是理论上100%，实战当下上就没有谁能保证了，看你的功力。**

说缠中说禅买卖点的确定的，就是缠中说禅利用人的贪嗔痴疑慢设置的幻象，是诳语！不了解这一点，你绝对不要用缠论实战，否则你会死得很难看，这是缠中说禅为初级缠迷挖的最大的坑。对缠中说禅来说，他能把握，但“缠中说禅的高（角）度不是你的角度”这是我一直强调的！

有人也许会说：背驰了就是1类买卖点了，是的，但这个1类买卖点不是事后的真正1类买卖点，只是最多可以回到前一中枢的买卖点，假设的1类买卖点，是不是当下无法知道的。注意前句话里有“最多”，就是指大概率。背驰就是回到前一中枢也要看着办，出现趋势性质的行情转折就一定是缠中说禅给你的幻象。背驰了，反弹2K至3K线又下跌，离上一中枢还远呢！这样的例子多了去了！懂什么是“幻象”吗？

缠中说禅从来也没有说过当下怎样判断1类买卖点？或者1类买卖点充分必要条件是什么？他只说带未来函数的1类买卖点。说1类买卖点当下确定的人一定是不会实战的人！或者不能稳定盈利的人。
