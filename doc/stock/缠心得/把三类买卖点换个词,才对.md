# 把三类买卖点换个词,才对

把三类买卖点换个词,才对。

**三类买卖点 ,应该叫三类买入方法**。

**这里的区别在于,三类买入方法,是正常的交易方法,而三类买点,则是未来函数。**

举个例子,三买回踩中枢上方买入,这是买入方法,回踩中枢不破三买成立,这是未来函数。

因为不破必须后面上涨才能看出来不破,而一旦下跌了,则三买就消失了,这也就是典型的未来函数,未来的数据变动会导致之前的判断产生变化。

而回踩中枢上方买入,无论后面怎么走,这都是不会产生变化的。

**这也就是为啥很多人画图都对,缠论实战抓瞎,因为画图是画的历史,因为未来函数的原因从来不会错,而忽略了实战会出现的问题**。
