# 关键不是预测走势，而是见招拆招 

能见招拆招，预测也便在其中了。

绝大多数人对走势的观察，都是滞后的，被动的，都只能等走势走出来以后才会恍然大悟：噢，原来市场出的是这招。

预测，必须建立在对市场招式的基本了解，以及对自身招式的熟练度以及相应反应速度的把握上。

一个刚学会篮球规则 ，连运球都运不利索的，你让他去防守一个职业球员 ，唯一的结果只能是：这个人被耍的团团转左右巴掌扇的找不着北。

有时候想想挺有意思：人们对类似篮球这类对抗性的体育运动，几乎很少有人会去特别强调对对手招式的预测，但是，偏偏在股市，绝大多数人却都不约而同的总想要去预测，而且想的都还是那种公式化的机械性的预测，总想着只要自己如何如何，就能躺在印钞机上财源滚滚了！

想的很美！

打篮球需要预测对手的招式吗？

当然需要。

不过，打篮球对对手招式的预测能力，能通过某个公式得来吗？

显然不能！ 但凡脑阔正常点都不会问出如此有见地的问题。

但在股市，却一大堆人不断在问此类题。

缠论，不过是用一种纯逻辑推导，将原本杂乱无章的市场走势，拆分成你可以看懂的一个个基于人四肢、身体组合的招式。

市场就是你的对手，他如何出招，是不可预测的；但他的招式却都绝对地无一例外地自同构地重复着

他手上、脚上、身体上的动作；这分解的一个个招式，都是唯一的，就像格斗，一拳就是一拳，一脚就是一脚，不存在三分之一拳，五分之二脚这样的说法，这就是缠论对市场的绝妙洞察。

缠论 ，把一个可以在任何方向向你发起任何形式攻击的像鬼魂一样难以战胜的对手，变成了一个有固定招式且只能在固定招式之间不断自同构性重复的跟人一样可以战胜的对手。

这才是缠论真正的打开方式。

去打打篮球吧，玩玩格斗也行，高手的气质都是相通的
