# 缠论三大系统的认识

缠师在文中提到了基本面、比价系统、技术面，用这三个方面通过概率叠加的方式，确保准确性。也在108课的最后面部分做了大致阐述，我也谈谈对这三个系统的认知。  

首先，基本面主要是针对板块来说的，**缠师说要找热点板块的龙头股，用大部分资金放在上面，小部分资金放在成长股上面**。

如何找出热点板块，和发现板块轮动的关系呢？  不妨参考一下其他模型，将全世界200多个国家和地区看做个股，那这些国家可以大致分为发达国家、发展中国家，根据地域也可以划分为七大洲五大洋。哪个国家是热点板块呢？当然得对比各个国家的GDP，而不是看增速、涨幅。

**所以，在A股上找热点板块就应该看行业、概念的成交额，来找最大的那个。**

其次，缠师在108课中几乎很少谈到比价系统，是否意味着缠师留了一手未透露呢？并不是这样的。

举一个例子：抖音直播间上万元的笔记本电脑，9成新，只要1000元，你买不买？这时候你会犹豫，会想是不是质量出了什么问题？老板跟小姨子跑了，公司要倒闭了？难道真是捡大便宜了？难道还有什么消息没出来？便宜无好货？  

所以，**比价系统是依附于基本面的，是基本面的一个补充，正常情况下用不到。除非你对基本面有了非常非常清晰的了解**，就像买水果一样，一眼就可以看出手中水果的基本面，从而决定，我该买哪个摊位的水果。  

总结来说：

1.比价系统是依附于基本面的，是基本面的捡漏，不了解基本面就不用看比价系统；

2.基本面和比价系统是战略方面的，决定干什么；而技术面是针对个股进行操作的，是战术方面的，决定怎么干；

3.一般情况下，可以忽略比价系统，用基本面选热点板块，只需要花非常少的时间即可；剩下的大量时间都是给技术面操作的；

4.基本面的热点板块选择，以通达信手机端为例，在板块一栏找“概念”、“行业”的“成交额”就能看到板块的轮动情况。
