# 学缠论还是学习利弗莫尔?

只学其中一个，会让你挨打到找不着路。

都要学，才能让你获得控制力和理解力。

为什么要有控制力和理解力？

炒股炒到最后，就是要把控制力和理解力提升到惊人程度，是一个炒股人能稳定赚钱的两个根基性能力。

缠论是技术界天花板，学会了你就拥用了进场能力买卖技术，能看懂一只股票的能力。

比如三类买卖点，从左侧到右侧进场都有，但是你具体用哪个进场就看你当时选了什么股票，做多长周期来决定。

说白了，缠论是你的刀术。

不过出刀之前，你如果不搞清楚对方是谁，为什么出刀？就成了见人就砍，见股票就做，这样就入魔了的。

**利弗莫尔，就是龙头炒股的代表，读懂了你就知道要去鱼最多鱼最大的地方钓鱼，并且学着查看当下的鱼好不好捉，下雨天总不能再去钓鱼了吧？**

这就是选龙头股了。

可是谈何容易？

利弗莫尔没几人能读懂，也值得一个人用一年以上读懂利弗莫尔，一个人入市第一年就能有此般明悟，那么炒股路不知缩短多少。

如果时光倒流回到十六年前，我就这么做，或许14年前我就能养成现在模样。

更详细有空再说说。

先简单捋捋：

炒股是一套系统流程，不是片面的买入卖出或者修心的单方面学习。

买卖之后，得有资金管理仓位安排。

买卖之前，得选股。

**选股之前，得确定你是跟利弗莫尔选股还是跟巴菲特选股？** (选股模型)

选股之前，又得看当下大势研判定仓位让自己不处危楼之下。

说到这，你get到了什么？

新手或许压根不知所云，老手也似懂非懂，高手看似懂了依然不懂，超级高手或许略微点头默默支持，这是无言的行动，只能感叹几人能做到呢？
