# 以小博大的艺术

1. 交易的核心是以小博大，以小博大的精髓是以小级别的一根关键K撬动小级别、中级别或大级别的一笔趋势浪。这就内在要求这根小级别关键K是小中大级别趋势浪的起始点，又或者说这根小级别关键K是小中大级别趋势浪对应的一笔回调浪的完结点。

2. 撬动趋势浪的级别越小，赔率越低，操作频次越高；撬动趋势浪的级别越大，赔率越高，操作频次越低。我个人建议你们撬动的级别要大一些，赔率更高，而且更重要的是更小级别出现的交易信号更多，一般人驾驭不了，胜率会降低。但也不建议过大，大级别的一笔趋势浪，必然包含中级别的一笔回撤，得到了再失去，而且失去的还是一笔中级别的回撤，一般人受不了。

3. 以小博大在技术层面上的精髓就是在小级别去找关键K。但你的视野不能因小级别而小级别，它必然是至少基于中级别出现重要信号，而后再回归到小级别去找我们想要的那根关键K或关键形态。你的主线逻辑至少是在中级层面。

4. 我为什么经常画趋势线呢？有些朋友说，画趋势线有个屁用啦。那是没有领略到趋势线的精髓。趋势线的精髓是同级别同性质波段极限位的连接点（重中之重），趋势线之所以叫趋势线，是因为它天然契合道氏波浪理论，它天然指引着某级别的趋势方向，有一定的概率，同一级别同一性质的下一个波段极点位依然会出现在趋势线上。譬如我们连接中级别回调浪的完结点形成一条趋势线，那么当价格再一次回调到这条趋势线上，它是有一定概率再次形成中级别一笔回调浪的完结点，这个位置就是关键位，需要我们密切观察，小级别有没有收关键K或者形成特殊形态以提升胜率，这时候我们下注，它就是在胜率与赔率层面有了保障。

5. 当然，很多时候价格没有回到趋势线位便已经企稳了，那是水平支撑阻力位形成了关键位。沿着趋势线的方向，在水平线支撑阻力位介入，也是我个人尤为钟爱的一种操作方法。不是因为趋势线有多牛逼，只是它天然契合了趋势的方向。

6. 有个别朋友在我帖子下面质疑技术分析的有效性。这个非常正常。其实技术面和基本面在我眼里没什么区别，都是寻找“拐点”。傅海棠老师在基本面关注的拐点就是企业的盈亏临界点，而技术分析关注的“拐点”，就是通过波浪结构、趋势线、形态等去判定你想要操作级别的可能的多空临界点。我个人建议对超出自己认知的事情，还是抱着一个空杯心态，这对交易中的成长还是有帮助的。
