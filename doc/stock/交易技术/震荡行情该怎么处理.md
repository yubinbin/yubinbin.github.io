# 震荡行情该怎么处理？

这个问题我也思考过，长久不得答案所以有段时间是放弃做震荡的。

后来翻书时候发现这么一句话：

> 市场总是试图突破，然后市场又试图让每一次突破都失败。这是所有交易的最根本层面，我们的所有行为也均以此为中心。
> 市场维持现状的惯性很强，因此改变面临巨大阻力。正如大多数终结趋势的试图会失败一样，大多数终结交易区间并开启趋势的试图也会失败。

然后突然明白了一个道理：

**单次交易的目的不是如何攫取最大利润，而是尽可能承受小的亏损的同时获得大的利润。**

**理论上能让财富增长最快的是尽可能平滑向上的曲线，而交易区间前后的震荡又往往是亏损最多的地方。**

**一个交易级别中真正的反转只会有那么一次，而突破失败会有很多次。**

因为散户的资金量很小，所以在配合止损的情况下，押注于反转失败的收益其实完全可以覆盖掉突破做错方向的止损。

而真正的趋势又往往不是短时间终结，而是会提供很多次上车的机会，等到反转趋势确认再上车即可。

所以在没有其他方面可供参考的情况下，不妨假设每次突破终会失败。
