# 从零到一构建一套交易系统实操案例

光说不练假把式，下面我们直接进入实操环节。咱们就以纯碱期货2409合约为例，讲讲怎样从零到一构建一套交易系统。

首先确定目标，你想捕捉哪一种行情？我的目标是：用均线捕捉一段超过一百点的行情。

选择平台与品种：国内期货交易平台，纯碱2409期货品种。

选择交易周期：我选择的是15分钟周期。

选择均线：我选择的是180日均线。

仓位管理：每次都是三成仓位。

如何入场：当K线的收盘价高出均线十个点时，入场。

如何离场：当K线的收盘价低于均线10个点时，离场，即止损。当盈利达到110个点时，离场。即盈亏比为1:5。设定110点是因为考虑到手续费和滑点的因素影响，我真正的目标其实是100点。

下面我们来看这套交易系统的盈利能力如何。

现在是2024年5月15日21:35:27

这个交易系统从2024年2月29日开始介入第一笔交易，距今为两个半月，如果完全按照上述交易系统进行交易，那么总共止损了9次，单次20个点，单手总计亏损180个点。盈利了3次，每次110个点，单手总计盈利330个点。盈利减去亏损，可以算出总盈利为150个点。

如果以一手纯碱的保证金为6000来计算，单手150个点的盈利为3000元。也就是说，这套交易系统的两个半月的收益率为50%。

如果你的初始交易资金为10万元，那么你这两个半月赚了5万。

如果你的初始交易资金为100万元，那么你这两个半月赚了50万。

如果你的初始交易资金为1000万元，那么你这两个半月赚了500万。

相信你通过这个案例也能够看出，如果你能够老老实实地坚持用一套交易策略，不要随便换，那么这种收益在复利的作用下是非常恐怖的。如果哪天遇到2021那种级别的牛市，完成财富的原始积累说不定一年就够。
