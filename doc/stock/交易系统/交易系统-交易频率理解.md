# 建立交易系统的核心

交易系统是交易员自己用的系统，是操作系统，指导操作的，是务实而不是务虚的。

最核心的事情只有一件，建立交易系统也是如此。有说是胜率、有说是盈亏比、有说是概率，都不能说错了。更好的，有说是同时考虑胜率的概率+盈亏比的概率，最后得出一个是否赚钱的概率。

但，这都不是最重要的。操作系统最核心的只有一点：**频率。即：找到最适合自己的交易节奏。**

按照操作系统严格操作，系统给你的操作机会是多少？一天几次还是几十次？一周几次？一月几次？一年几次？你自己内心决定舒适的操作频率是多少？这个才是操作系统的核心，才是最重要的。很多文章都说操作系统一定要符合自己的性格，那么自问一句，性格是什么？自己怎么知道？如何验证是否符合自己的性格？我一直觉得，用性格来形容操作系统，就是务虚了，就是忽悠。

比如说海龟系统，是能挣钱，但包括海龟交易员写的书也说，很多当时一个班上的学员，也有很多坚持不下去，要么急于进场，要么急于离场。从系统的角度，当然是学员的耐心不够，不能知行合一。

但实际上，是因为这种一个月或者一年才有那么几次的大盈利的交易机会，已经磨光了大部分人的耐心，实际上就是：大部分人，渴望的交易频率是一周有几次交易机会，最好一天有几次就更妙了。

有人说，为了能赚钱，我能忍受几个月交易一次的机会。老实说，我当初也是这么认为的，实际上没做到。一般人是从每天都有交易机会，慢慢修炼到每月几次也能接受，后来修炼到一年几次行，或者几年一次也行。

把这个琢磨明白，然后去打造自己的操作系统。重点就是，你现在能接受的交易频率是多少，或者说，什么样的交易节奏你觉得舒适？这才是打造自己交易系统的核心，无须先修炼耐心。
