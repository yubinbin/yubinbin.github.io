# 级别、趋势、位置和信号

市场的噪音太多了，各类专家、学者、营销号，几无实战能力，但他们的音量最大。普通人通过信息搜索，往往最先接触的就是这类垃圾信息，最易误导人。这就导致许多人的脑袋瓜子是混沌状态，看不懂市场的，也不知道自己要的是什么行情。确实学了许多东西，但是一团糨糊的状态。所以，**这篇文章，就想去提纲挈领的帮大家搞清楚交易系统的构建要素。你知道框架要素是什么，那么你的发力、你的学习的目标就会很精准了。**

交易，无非就是一买一卖，买多少，卖多少，分别对应的是开仓策略、平仓策略和资金管理。限于篇幅的原因，本篇仅介绍开仓系统构建要素。

开仓系统的构建有四个要素：量级、趋势、位置和信号。这四个要素互相关联，但每个要素本身也都指向了它自身的主要方面。简单来说，**量级定赔率与频率、趋势定方向、位置定入场，信号定胜率**。你们在学习的时候，一定要紧紧围绕这四大要素发力，但不能割裂的看，一定要联动的看，最终融为一体，形成开仓体系。

量级。首先要搞清楚自己交易的量级。通常来说，交易的量级越大，赔率越高，机会出现的频率越低；交易量级越小，赔率越低，机会出现的频率越高。交易机会量级的选择，与资金规模、个人性格秉性密切相关。我们到这个市场来，首先要确定自己的交易量级。周线级别的一个波段在日线级别就是一个完整的流畅趋势；日线级别的一个波段，在30分钟级别就是一个完整的流畅的趋势。你明确了自己交易的量级，你的交易频次、持仓周期也就定下来了。交易频次与持仓周期是与你的交易机会的量级相契合的。这就话很重要的。你做日线趋势就做日线趋势，你做日线波段就做日线波段，你做日内就做日内，这没有什么好坏之分，但只有明确了自己的交易量级，才能审视自己开仓的频次、持仓的周期有没有问题。我个人是建议普通交易者交易量级放大一点，赔率会比较搞，大级别趋势也是包含了主力资金在内的资金沉淀，结构比较稳定，想要逆转这类型的趋势，可能性也会比较低。

趋势。趋势为我们的交易指明了交易的方向。我们交易，肯定要明确我们的交易方向是什么的。是要做多，还是要做空？这是交易的性质问题。只不过，脱离了级别谈趋势是没什么意义的。顺势而为，这里的顺势是顺大级别势，顺大逆小。一个日线级别的上升趋势，包含了主推浪和回调浪，而回调浪在30分钟级别，可能就是一笔下跌趋势。所以，趋势方向的判断，离不开交易级别的联立。你做日线趋势或波段，就耐心等待回调这一笔下跌趋势的完结（逆小趋势）。我们在谈趋势的时候，同时还会涉及趋势的定义。市面上，有道氏理论、趋势线和21日均线等都可以作为对趋势的客观定义。也因为有着对趋势的客观定义，那么，顺势而为也是一个客观的操作动作，它不是预测，而就是对当下客观趋势定义的介入，赌它的延续。趋势，还涉及到趋势运行的类别。有大开大合型、有N字型、有楼梯型、有陡峭型、有扇形加速型等等，不同的运行形态，止盈的方式也会不尽相同。

位置。当明确了自己的交易量级，明确了了交易方向，还要考虑在市场中的什么位置中介入。顺势交易，最核心的交易位置就是两大类。一类是顺势突破位介入，一类是顺势回调位介入。顺势突破位，通常是一波主升之后的震荡区间，震荡区间呈现规整形态（如长矩形、三角收敛结构、旗形等），顺着主升浪方向突破此规整形态，往往代表第二波主升的开始。

另一类介入位置是顺势回调位。回调到哪里完结？常见的有回调至强阻力位、回调至斐波那契位、回调至均线位、回调至趋势线位、回调至通道下轨位，又或是回调内部结构完成123法则的次级别反转，亦可作为回调的完结位。不同的交易技术对回调完结位的定义与捕捉亦是不尽相同，技术为市场立法，每个人对市场优势位的理解都不一样。

信号。明确了交易量级、交易方向，等到了价格运行到优势位置，是不是可以开仓了？还不行。还要有信号去规避成功率低的机会，去捕捉胜率高的行情。价格运行到关键位置，一定要看它的强弱转换。该弱的地方一定要弱，该强的地方一定要强！比如，顺势突破，在突破前有没有蓄势？有没有增仓？有没有放量？是不是中大阳关键K突破？再比如回调位介入，回调在次级别结构有没有呈现底背驰？有没有出现强弱转换关键K？这些都是信号。先胜后战，我们只站在胜者一边，在客观层面，我们看到我们所期待的一方确实打了胜仗，我们才去下注，要于我有利。

顺势交易，不管你再怎么花里胡哨，其开仓系统的构建都脱离不了上述的四大要素结构。你有了框架，而后就往里面有机的填充内容，结合自己的思考，秉性，内化为自己的东西。最终的目标是要做到精准化入场。以次级别的一根关键K去撬动更高阶的一个趋势或波段。到这，再结合资金管理与平仓策略，有机会成了。
