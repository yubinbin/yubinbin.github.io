# 什么时候你意识到要及时止损？

在刚开始作交易的时候，不懂得止损，而且当发生亏损的时候，由于自己没有设止损，大多数时候都能让我抗回来，也慢慢强化我不止损的习惯。当我因为一次不设止损，亏损死抗，甚至浮亏一路加仓，导致自己最终爆仓出局的时候，我才真正意识到要及时止损。

止损包括成功的止损和失败的止损，成功的止损是指你在止损后市场继续向坏的方向发展，避免你出现大的亏损。而失败的止损，是指市场在你止损后又回到原来的方向，向好的方向继续发展，如果不进行止损操作，结果有可能是盈利的。

作为一种平仓的操作，止损必然会有两个结果：成功和失败。

**所有失败的止损都有助于你的交易，它能确保每一个成功的止损都能被执行，为了抓住每一次坏人，我们不得不误伤一些好人。**

成功和失败的止损，就像秃鹫的翅膀，确保了它展翅翱翔的能力，因此必须接受成功的止损，也必须接受失败的止损，要理解止损就必须理解错误的止损，为什么强调必须接受失败的止损，**原因在于在充满风险和不确定性的金融市场中，风险永远是第一位，其次才是利润，不止损有一天是要付出惨痛的代价的**。

许多人不能严格的执行自己的止损计划，当经历连续止损的时候，很多人经常会改变自己的止损点。因为他们经常说市场已经改变了，谁能确定一个坏的交易，死扛下去不会变成一个好的交易呢，这也是大多数人交易的想法，他们担心在平仓后市场开始向原先预期的方向发展。

不过如果他们不早点砍仓，等市场越走越远，可能就会变得越来越难了，最后遇上一波大的反向行情，因为死抗就会一朝回到解放前，这种巨大的损失，总有一天会把你赶出市场，你要注意，让你的损失越小越快割肉并不总是对的，但它可以保证你在能在这个游戏中继续生存。

大多数交易者通常不知道，**交易实际上是一场输家的游戏，最擅长输的人最终会赢，交易不是赌博，把它看做一项生意去做，把他当做自己一生的事业去做这些，平常不断的小磨损就是你做生意的成本。你应该把风险降到最低，让利润最大化**。

如果你有过止损的经历，你会更快的学会如何止损，但是你要养成坚定的止损，就算出现连续亏损也能坚定的执行自己的预定止损爱上止损的这种行为习惯，代价实在是太高了。

新手规避止损，高手拥抱止损，止损和连亏是好东西，它让我和大多数亏货分开。
