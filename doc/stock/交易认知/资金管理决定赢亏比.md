# 交易的核心是概率吗？

盈利预期

将3倍赔率作为盈利预期是胜率30%的赔率需求。

投入一笔资金，静静等待仓位在市场的运动下-1、0、3输出其中之一结果，那么这笔交易完全没有资金管理的参与必要，这一切都只靠市场的运气，其命运看的是硬币扔的是否”准确“（入场点与技术分析），还要什么资金管理。

从理论上而言，仓位调整起到的作用在于：

让1：3的赔率

使得-1尽量变成0的前提下（在浮盈达到1时，挪动止损），获得3的结果赔率。

加上短线的限定，就有了另外一条：

通过加仓让使得仓位在“1”时加速变成3。

资金管理就是在这个位置发挥它的作用，它是一个加速器。

交易中最大的不确定性，不怕它直接打止损，而是打出去之后，就差一些达到预期3反转回撤了，而我们需要通过调整仓位使其在市场反转之前达到所需要的预期获利出场，在保证仓位安全的前提下缩短这个过程，这是我认为资金管理的核心所在。

请问这种是概率吗？这种加速行情随处可见。

交易胜率并不是纯粹的运气因果游戏——交易后单子要么打到止盈，要么打到止损，而且还能满足胜率。只要我们在某个条件下入场持有不动，就能实现所谓大概率打到止盈的你觉得这个逻辑可靠吗？

因为太简单了，这个点位或条件如果存在的话一定被试出来了。

关键在仓位的调整上。

通过仓位调整加速达到预期，从而获得高赔率下的一定胜率，而不是进去后，持有等待走势达到预定目标，哪有这么多牛逼行情打到你的预期。
