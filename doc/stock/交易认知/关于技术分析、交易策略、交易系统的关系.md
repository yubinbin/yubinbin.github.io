# 关于技术分析、交易策略、交易系统的关系

## 什么是技术分析？

技术分析，最核心的思想就是分类，只是把市场进行完全分类后指出在自有交易系统的视角下，什么是能搞的，什么是不能搞的，如此而已。技术分析系统之所以重要，就是因为对于一个完全没有消息的散户来说，这是最公平、最容易得到的信息，技术走势是完全公开的，对于任何人来说，都是第一手，最直接的，这里没有任何的秘密、先后可言。技术分析的伟大之处就在于，利用这些最直接、最公开的资料，就可以得到一种可靠的操作依据。单凭对技术分析的精通与资金管理的合理应用，就完全可以长期有效地战胜市场，但如果光把技术理论搞清楚，是运作不了主力资金的，技术层面只是一个基础，因此，对于散户来说，你无须知道这天上掉下的馅饼是怎么制造的，只需要知道怎么才能吃到这馅饼。——此段节选自《缠中说禅》

## 技术分析在市场上的可行性？

站在散户的角度，市场是不确定的，不可预测。这么想的不仅仅是初入市场的新人，更不缺的是市场沉浮多年的老鸟。那么问题来了，如果不存在这种方法，那么市场上流传的传说是怎么做到以小博大，实现财务自由的？难道全都是靠运气？内幕？或者全都是别人杜撰出来诱骗新韭菜入场的？要想在这个市场上活下去，运气只是一时的，内幕也不是天天都有，要是没点实力，给你机会你也不中用。市场上的传说主角有多少是真正科班出身的？那些基金经理各个不是硕士就是博士，现在那些基金什么情况，大家有目共睹。基金经理挣的是管理费，基金本身的净值跟她的收益有多少关系？有良心有实力的基金经理没事给基民搞一搞，尽量不大亏，没良心没能力的，她管你死活？你要说所有的基金经理一点实力都没有，你信么？基金经理和基民的利益都不在一条绳上，哪里靠得住。

## 什么是交易策略？

交易策略其实就是在市场上摸爬滚打多年后形成的经验，市场上能获利的绝大部分人都掌握着至少一种成熟的交易策略，交易策略属于“术”的层面，网上所教的各种战法，理论，卖课出书的，99.9%都只停留在这个层面上，甚至绝大部分策略都属于毫无逻辑支撑的垃圾，能盈利的策略，非亲非故，毫无渊源的，谁会放出来？你要相信人都是有私心，闷声发大财难道不是咱们每个人的共性么？

## 什么是交易系统？

交易系统，包含策略和心法，讲心法不太恰当，应该叫原理或者逻辑，交易策略只是交易系统的一部分，更要去深究策略的背后的原理，策略告诉我们该怎么做，逻辑告诉我们为什么要这么做。散户有好的策略有可能战胜市场，但要想长期稳定的战胜市场，光靠策略是不够的。

## 如何构建起属于自己的交易系统？

正所谓“有道无术，术尚可求也，有术无道，止于术。”在学习一套理论时，最重要的是去理解其中所蕴含的“道”，然后从“道”的角度去看“术”，否则大概率会沉沦于“术”，就算运气好，让你学会了“术”，光知道怎么做，却不知道这么做的意义，就永远只能停留在“术”的层面上。如“千人千缠”，说的是在同“道”下诞生的不同“术”，而不是什么一人一道，道道不同。何谓“道”？市场本身充满了不确定，首先就要在不确定的市场中找到其中的确定性，确定性不是大概率，而是100%的确定，然后根据你能确定的东西去制定相应的策略。就算你一时找不到100%，好歹找个百分之八九十做“道”基吧？不过我也没见过八九十分的“道”基，稳健一些来想，八九十分不就约等于零么？

交易系统的强弱，从“道”的牢固程度就已经决定了，修真小说中，同等修为下以本源大道为核心，以招数为外在表现，以胜负为结论。在交易市场中，同等认知高度下，以确定性为核心，以策略为外在表现，所谓的成功率和盈亏比只是结论的其中一种表现形式罢了。很多人容易本末倒置，复盘的时候得出一个一个成功率和盈亏比还不错的策略，就以为找到了交易圣杯，结果就是复盘结果很理想，实战起来一地鸡毛。

其实要不要写这篇文章我犹豫了很久，其实文章开头在周三晚上就已经在草稿箱里了，但是写着写着就变得有点烦躁了，人都是自私的，万一有天赋异禀之人从中推导出了和我一样的交易系统，会不会导致我的交易策略在未来某一天失效或者降低效率？那岂不是自找麻烦。

就如缠师所言：“有人经常担心，万一人人都学会本 ID 的理论，那么本 ID 的理论还有用吗？问这种问题的，基本就没搞明白本 ID 的理论。而且，人人都学会本 ID 的理论，这本来就是一个假命题，像孔男人这样的文科生，本 ID 从来都觉得他们能学会的机会比较渺茫。注意本 ID 这里是有定语的，没有打击所有文科生，而是说孔男人这样的文科生。当然，如果有人爱自己往孔男人这样的文科生的套里去，本 ID 没什么意见。”

市场是残酷的，有人说，市场是老人挣新人的钱，而市场中的老人，套个 10 年 8 年的一抓一大把。其实，市场从来都是明白人挣糊涂人的钱。在市场经济中，只要你参与到经济中来，就是经济人了，经济人当然就以挣钱为目的，特别在资本市场中，没有慈善家，只有赢家和输家。而不会赢钱的经济人，只是废人！无论你在其他方面如何成功，到了市场里，赢输就是唯一标准，除此之外，都是废话。——此段节选自《缠中说禅》

交易到了一定程度以后，交易其实是一件无比枯燥的事情，除了下单的时候敲两下键盘，99.9%的时间都是无聊的等待，一直在重复，不是在等买点就是在等卖点。哪怕是现在，我盯盘无聊的时候也会逛逛知乎，偶尔也会刷到交易或者《缠中说禅》方面的话题，但早已不是抱着优化策略、完善系统的心态了。更多的是去了解其他人的理念，不管是知友的还是缠师的。当然这是在自身系统已经相对完善的情况下，不然接收太多这方面的信息反而会让操作变形。其实我之前的担心多少有些多余，因为哪怕是同“道”中人，每个人的人生经历是不同的，所积累的经验，多接触过的形形色色的理论也有所差别，所以要真有人能做到跟我的操作完全同步，那多少有点恐怖了。光有“道”，没有“术”也白搭，但是只要先有“道”，“术”只是早晚的事，先有“术”却无“道”，难入门尔。

不管是“术”的优化还是好心态，多交易多实战，总会好起来的。好的交易状态是靠交易系统保障的，没有交易系统保障的心态，那叫躺平摆烂，毫无意义。

诸位，道阻且长，路上行人稀，且行且珍惜，十年八年走不出来还沉迷其中的一抓一大把，别因为交易搞砸了生活。最后能走出来的，大部分都是置之死地而后生过的人，能别经历还是别经历的好。
