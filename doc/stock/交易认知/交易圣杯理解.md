# 我的交易陷入了迷茫，请问该怎么突破？

你走入了一个误区，你认为挣钱的关键在于方法，这也是很多散户认知的误区。他们认为:这个市场应该存在一个圣杯，存在一个一劳永逸的方法，这个方法简单可复制，只要找到了，这边输入一个买点，那边输出一个卖点，钱就哗哗的来了。如果不挣钱，那肯定是方法的问题，是股票的问题，是市场的问题，是政策的问题……总之是外部的问题。

早期的时候，K线里有杀气说过一句话:哪怕再简单的方法，只要你执行的好也可以变成抢钱利器。反过来，给你再好的方法，你执行不好，也一样赔钱。高手可以飞叶杀人，小孩子给他个屠龙刀他可能都拿不动，所以交易更多是个向内求的事情。

首先先把认知搞正确，搞清楚市场的本质，搞清楚自己在市场里的角色，认知会决定你的方向。打个比方，我认为市场是不确定的，那我就不会刻意去关注预测性的方法和观点，凡是宣称自己搞精准预测的，一概认为不入门，那你就不会朝这个方向浪费精力；其次多看公认的、经典的、符合你认知的交易类书籍，完整系统的去学习，而不是跟知乎这样，碎片化的去讨论，看看成功的前辈们怎么把这条路走通的，他们的经验教训是什么，站在从他们的肩膀上构造你的交易的策略就可以了，有很多现成的，你要照抄都可以，这个反而是最简单的，迈克吴，陶博士不就是抄的欧奈尔吗？一样能在这行挣钱吃饭；然后执行过程中多总结多复盘，找问题，解决问题，问题会有很多:认知的，人性的，计划的，风控的，执行的……一个一个去解决，这行是短板决定收益，你解决的越多，你的短板越高，留下的钱会越多，这个是长期的水磨的功夫。

写到这里，想起我认识的一个人，他也走过这样的弯路，20多年前就在期货公司，做期货的居间人，学了很多方法，行情好的时候也挣过很多钱，但是留不住，每次行情不好都亏个精光，他每次都认为是他的方法不行，技术分析、价值投资、龙头战法、打板……一个一个的试，用用觉得不好就换，狗熊掰棒子一样，什么都知道，都用过，但是哪个都不长久，我有时候开玩笑说他是技术油子，啥都懂，就是都不精。他以为是方法的问题，其实是他自己的问题，这些方法都有人挣过钱，但是他对哪个方法从来都没有充分的信任和良好的执行，他以为挣钱靠方法，其实更多取决他的这个人，但是他很少去反思自己的贪嗔痴慢疑。很聪明很努力的一个人，在方法上蹉跎了很多很多年，最后有一次家里闹矛盾，他家人把他的电脑也砸了，书也撕了，不让他再做了。很残酷很现实的一个例子，引以为戒！！！
