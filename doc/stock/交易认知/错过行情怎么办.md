# 炒股的精髓是什么

当我发现错过很大一波行情后，在这种情况下，我产生了一些心理障碍，就想把它完善一下，把这个没抓到的这波行情，通过调整系统把它抓住。

这个时候我就开始降低标准，最后就乱了，频繁止损，把系统这个概念都忘了。

这种情况持续了很长时间，最后我遇到了一位老师，他指点了我一句话，这句话让当时的我恍然大悟，他说只做自己交易系统内的行情，能明确舍弃系统外的行情，这就是交易的终极密码。

其实之前有人跟我讲过，但我却是听不懂，也听不进去，我现在的感悟就不一样了。

我现在的感悟是什么呢？

不眼红自己交易系统捕捉不到的行情，这就是我认为的交易精髓，也是最高境界。

可能很多人都不会认同我这句话，和我当年一样要么听不懂，要么听不进去。
