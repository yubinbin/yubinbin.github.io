# 交易规则是为交易者量身定制的交易武器

初级交易者常常根据感觉来交易，而顶级交易者根据交易规则来交易。

吸引很多人进入交易行业是因为自由，门槛低，任何人只要开户入点金就可以交易，你只需要对自己的账户负责即可，动动鼠标就可以轻易完成一整个买卖的过程，极度高效。

这是最大的自由，也是最危险的陷阱。在利益的波动面前我们会失去控制，顺从人性的弱点，在市场上为所欲为。

比如，当我刚开始交易时，我会轻易因为一个专家的判断，或者一个利好的消息就轻而易举的入场交易。当自己的头寸发生亏损的时候，也会因为自己的看好后市，而坚定的持有，亏损死扛。

越是自由自在，就越容易纵容自己，这就是人类的本性。所以进入交易市场，我们想稳定盈利，就必须要控制自己人性的天性，而所有的这些都需要建立交易规则。

**交易规则是什么？他就是，一个交易者在混乱的市场走势下做出的一系列反应。**

全部交易规则包括：

交易者的选择、进入、退出、资金管理等规则。

只有在交易规则中描述的特定行为被触发时才采取行动。

比如，利弗摩尔的“只在上升的市场上做多，而在下跌的市场中做空”，比如海龟交易法则的“突破20天高点，果断开仓，反向突破10天低点离场出局”等。

为何利弗摩尔只在上涨过程做多？

这是因为他长期的交易生涯中，他发现利润来源于趋势行情。所以你要尽可能的抓住趋势，而在波动的市场中想要抓住趋势，你就必须要顺势而为，必须要顺势跟踪，所以就要在上涨过程只做多，下跌过程只做空，这样才更有利于抓住趋势行情。而不是什么行情都做，不要想着抓住所有的波动。

为何海龟交易规则在突破20天高点就作多？

这是由于海龟交易法则的创建者们知道，当趋势形成的时候，价格必然会突破前20天高低点。所以他建立了一套趋势追踪系统的交易规则。

交易规则是为交易者量身定制的交易武器，他以自己的认知为基础定义了混乱的市场。

比如均线交易者，他用一条移动平均线来定义市场，他把市场划分为两个方向。在均线之上作多，在均线之下作空。他们不看其他的任何东西，他们根据均线来定义自己能交易的市场。

他们只需要把精力集中在自己确定的市场上。市场是一张白纸，交易规则是画家的画笔。

交易规则并非无稽之谈，交易者的交易规则包含了他的交易智慧，那是他交易哲学的总结，结晶，这背后包含了他对市场的取舍，包含了他的选择路径。

由于市场中有很多机会和欲望，严格遵守规则的交易者不会骄傲自大，没有达到自己的交易规则入场信号，他就会等待。

他等着自己的规则被启动，他等着市场出现属于自己的信号再交易，弱水三千，只取一瓢。

而初级交易者往往根据市场的波动，根据当下的感觉来交易，他们的交易毫无章法，注定失败出局。
