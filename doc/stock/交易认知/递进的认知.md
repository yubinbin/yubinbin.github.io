# 你是在什么情况下才领悟到自己的交易系统的？

交易系统，

买卖点，

仓位，

心理，

策略一致性。：

分阶段。

1. 刚开始，是找策略，大多数说买卖点不重要。

2. 中后期，强调心理，仓位，一致性。

个人说下体会一

1. 一开始仓位重要，下场不熟，钱别输光，但是吧也没用，新人，老人都控制不住的。

遵循一个原则，前期投入一个固定金额，别充钱就行了。

2. 中期主要是策略，花三到五年都正常，策略并不是赚钱方法，是观察市场的绝对视角，之后才能发现其中交易模式，才有下场机会。

3. 后期是心里，模式连续赢利，人会想赚钱上仓位，这个时候，一般人早被打废了，上仓位克服不了，永远停止。

上之后，大回撤，会怀疑人生，不知道合不合适，这个时候，止暗时刻。

4. 最后是一致性，万法归一。

**什么都是虚的，买卖点就是一致性。**

**买卖点从不重要，立即上升到90%，策略是应对，基本生存之道，不重要了。**

**心里也不重要了，要亏就亏。**

**仓位重要一点点，可变化的弹性并不大，跟着买卖点变化。**

最后，交易只剩下你，

你看到什么，交易什么，纯认知。

体现方式，最终二个字，

机会=买点。

风险=止损。

这是悟道篇所有内容了。

没啥保留的。
