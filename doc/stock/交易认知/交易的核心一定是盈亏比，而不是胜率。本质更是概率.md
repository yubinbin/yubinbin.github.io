# 交易的核心是概率吗？

交易的核心一定是盈亏比，而不是胜率。本质更是概率

一笔足够赚钱的单子，可以覆盖掉你多笔的小止损。

期货本质是试错交易，在试错中寻找正确的方向。

盈亏比对应的背后是趋势交易策略，而胜率对应的则是短线交易策略。

趋势交易一般胜率大概在30~40左右。意思10笔单子，可能6~7笔都止损掉了，剩余的几笔持仓赚大钱。

短线呢，则要求更高，快进快出，底层逻辑胜率就必须高，要不然你快进快出的同时，一方面手续费是一个大头，你的亏损更是一个大头。

如果你短线连续亏损几次，控制不好手，你心里的可能更多是想赢回来，此时你就会变成一个赌徒，而不是在做投机交易。

短线有做的好的，我认为一万个里边有两到三个长期赚钱的就不错了，但是我觉得普通人很难做好。

包括我，我看一下盘面，总感觉有很多机会再等着做，我只要一投入，我原本制定好的机会，都会被盘面波动而受到影响，从而管不住手。


短线的结局，我认为是赚小亏大，爆仓出局。


那么做趋势呢，就相对好做很多，不需要你去盯盘，正常你该干嘛干嘛，期货本身的波动影响不了你。

做趋势难的地方不在于你对品种的多空判断，以及关键点位的入场，以及具有关键意义的止损点。

做趋势难得是坚守规则，与时间做朋友，敢于持仓，敢于面对盈利的回撤。

底层逻辑则是对一个人心态、格局的考验。


做趋势不需要误打误撞，是有明确的判断标准。

我用的是28日均线，我把它理解为趋势多空反转的重要分水岭。

28日线上开多，28日线下开空。

一句话，大道至简，最简单的方法，去应对最复杂的市场。


当然也有很多人用均线，例如大部分用20日均线，非常有效，但是参考的人太多!

还有很多人使用60日均线，他也是重要的多空分水岭，但是60日滞后比较严重，等你准备参与的时候，行情已经走了一大截，所以我不参考60日。


我用的28日，则是在其中，中和了两者的趋势特点。


想做趋势交易，则需要明白一下几点


1.判断品种多空的能力 （基本能力）

2.寻找合适的入场点位 （学会等待，不随意下单）

3.清晰的止损逻辑 （避免大亏的前提）

4.清晰的止盈规则 （避免利润大幅回撤）

5.大格局持仓能力 （与普通散户操作拉开的重要能力）

6.大周期交易（降低交易频率，间接降低止损概率）
