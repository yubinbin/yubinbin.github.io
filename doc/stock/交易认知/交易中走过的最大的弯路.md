# 作为交易员，你在交易中走过的最大的弯路是什么？

蓦然回首，交易之路已走了16年，股票，期货，外汇，一路走来实属艰辛，走过最大的弯路，莫过于寻找确定性。

一开始是研究各种技术指标，试图预测未来的走势，后面慢慢研究各种形态，各种理论，各种XX论，试图找到某种规律，都是想要预测未来的走势。一晃几年过去了，走了几年弯路才知道，**入场只是一个试错的开始，重要的是你入场后如何处理你持仓的风险和收益**。

交易行业，十年磨一剑是必须的，这个剑就是你的交易认识，你对交易本质的理解，我从来没有看过一只交易两三年就对交易的本质有很深的认知和理解。

其实交易的真相就像山上的一座塔，它就静静的躺在那里，等着我们去攀爬，但是难的不是我们要爬上这座塔，而是我们要寻找到它的路口
