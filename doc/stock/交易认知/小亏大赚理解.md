# 抛开技术指标看股票交易的做法

在大多数人感觉中，炒股厉害的人都是技术好的那些人。所以乍一看离开技术，似乎就不会操作了。

今天我就谈一下，离开技术指标这些看起来牛批哄哄的东西，我们要怎么交易。

大家都玩过石头剪刀布吧，每次猜算，你能得到的结果有三个：输，平手，赢。对吧。这个叫做随机系统。

股票也是随机系统。每次介入一个股票，你能得到的结果都是亏，平，赚。我们使用交易技术，研究基本面，打听消息这些东西，都是为了提高我们的赢面。但是绝对没有100%的胜率的。这里插句题外话，如果有人说他的胜率超过60%，你都可以说它是个骗子。

在交易过程中，由于交易费用的存在，我们要面对的其实只有盈和亏两种情况。而盈亏呢，我们可以分大亏，小亏，小赚，大赚。这四个纬度，随你怎么界定，我一般是用13%来分。超过13%，要么硬抗到翻倍，要么微赚出局。（这个个人喜好，不喜勿喷！）

**大亏  ->  小亏  ->  小赚  ->  大赚**

那么，这四个纬度，我们能够去掉其中的某个纬度，可以吧。

先看看去掉大亏。去掉大亏后，剩下小亏，小赚，大赚这三个纬度。**怎么去掉大亏呢，个股亏损13%，无条件止损。那么，在足够多次的交易中，可能小亏和小赚的钱就互相抵消了；只要有那么几次大赚，账户就起来了**。

再去掉小亏试试。去掉小亏后，剩下大亏，小赚，大赚三个纬度。怎么去掉小亏呢，就是不设止损。要么抗到大亏出局，要么吃汤喝大肉。那么，在足够多次的交易下，可能大亏大赚的钱就互相抵消了，而小赚的钱就是你的利润。

去掉小赚行不行，也可以。要么不赚，赚就要赚把大的。

去掉大赚行不行。这个也可以啊。大多数人都是这么做的。这也就是大多数人亏损的原因吧。

可以去掉两个纬度么？比如去掉大亏，小亏。这个要求比较难，这个要保证个股哪怕跌了也会涨起来。至于涨不涨，天知道。去掉大赚，小赚，可以么？也没办法，万一运气太好，就是买了就涨。去掉小亏小赚行不行？有些个股就在某个区间横盘震荡，不上不下。

好了，现在你只要选择你喜欢的模式就可以了。

你看，炒股是不是就变得简单了。不需要看指标，不要什么公式，只要有个好的模式就可以赚钱了。至于怎么设计这样一个交易系统，那就是另外一个故事了。
