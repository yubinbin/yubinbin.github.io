# 顿悟交易的精髓:截断亏损，让利润奔跑，至于怎么截断和奔跑就看自己的术了。对否？

完全正确。

截断亏损，意味着你拥有了控制住损失的能力，而让利润奔跑，代表了你能够承担回撤在趋势中持有到正确的仓位。

这就是投机交易领域中的明牌的东西。

投机之王，杰西利弗莫尔说：了结亏损的头寸，保留获利的头寸。这句话翻译成中文是什么？截断亏损让利润奔跑而已。

华尔街幽灵的规则一：在走势没有证明你是正确的之前，已经建立的头寸必须不停的减少或清除，这是啥意思？截断亏损让利润奔跑罢了。

截断亏损是控制风险，而让利润奔跑是让你能够在趋势中获取足够多的利润覆盖掉成本，纵观各行各业，哪个领域不是这样？

大道至简，同时，大道也相通。

截断亏损让利润奔跑的逻辑，可以让你在不确定的K线走势中获得正向收益预期，就跟赌场基于赌客设计出的概率优势一样。

它就是交易领域中，最根本的核心之一。我把它称为：交易逻辑。

至于你如何设计具体的交易行为去实现这个逻辑，基于什么周期，什么级别，采用了的是裸K，均线，还是算法，这些都是细节而已，就是题主所言的：

术。

术没有标准，你只能依靠自己，因为这跟你的经历，你对风险的理解，你的风险承担，你的获利预期都息息相关，没有绝对的标准。

最后，恭喜你。你的顿悟很有价值。
