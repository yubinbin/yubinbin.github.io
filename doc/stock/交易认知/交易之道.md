# 交易之道

1.做好止损

不只是让你做好止损，而是做“好”止损，你的止损需要大多时候都有用，不然就是钝刀子割肉，你的止损需要是你反向进场的位置，也就是在这里，你有一点理由反单，但你可以不反。

2.顺/逆势

这个问题也很简单，看清你的跟随级别，然后记住当下，顺势和逆势都是一个势，市场的真实方向。

3.时间止损

单子持有过长的时间不是好事，固定时间没走出利润，要主动及时止损。

4.频繁交易

频繁交易我认为没有对错之分，本质上是交易员对有效机会的认知不够，导致的无用交易，也就是你的交易并不能产生实际空间，如果对机会的识别准确点，自然就不会频繁交易了。

5.抗单

抗单也没问题，不是错，也不是对，这个我知道会有人杠我，要站在级别看问题，你给5个止损和10个止损，在未打损，却浮亏，这其实就是抗单，我有时候短线盈亏比会1/10或者2/20，用很少的止损，就拿大利润，中间还可以再加点仓，实践证明，利润和亏损无什么关系。

6.公平原则

对市场要公平，小级别图小利润，大级别要图大利润，不能在5分钟级别的信号，抓日线利润，不是抓不到，而是成本太高。

7.不要频繁换方向

市场在很长一段时间，只会保持一个方向，哪个方向过去经常给你利润，就做哪个方向，多空虽然都有利润，但多空也都有止损。

8.基本面和技术面

在大级别，基本面和技术面本质上是一个东西，基本面预判技术面，用技术面进场做基本面，或者用基本面预判技术面突破，效果都不错，但基本面有点玄乎，不要不信基本面，但也不要太信基本面，有些基本面是骗不了人的，比如战争，大选，口罩，而资金的流入流出，是可以骗人的，多头市场哪怕有百分百把握，也别空，有百分之50把握就多，市场会放大你的胜率。

9.结构

交易者要看年线，mt4没有年线，就是为了筛选不看年线的，年线代表市场的最真实方向，比任何技术面，基本面都靠谱。

10.公平

还是公平原则，偷奸耍滑，剁手剁脚，保住利润，比什么都重要，不要扯什么格局，利润止盈需要关注级别，大小，遵守先进先出原则，大级别大止损，后止盈，小级别小止损小止盈。

11.悟道的本质是拥有看懂行情，处理单子的能力，而非盈利，盈利是老天给的，这在华尔街可能是基础，交易路慢慢，唉，市场没有错和对的区别，只有正确的人，频繁交易，重仓，抗单，不止损，这些都错，但也都对，轻仓，顺势，这也对，但也是错，基本面交易那也没止损，照样挣的挺好，市场无对错，对和错是人为划分的。
