# 交易中的“圣杯”真的存在吗？

对于绝大多数刚进入市场的交易来说，那些在市场中赚到钱的成功的交易者都有一个交易秘诀或者说“圣杯”，知道了这个“圣杯”，他们就能像那些成功的交易者一样赚到财富，这个所谓的圣杯就是通往市场的顺序，类似于该买那只股票，具体什么价格买，什么价格卖。该做多或者做空某一个商品期货，具体的价位是什么。他们最终追求的是确定性，所谓的圣杯就是确定性。

对于绝大多数刚进入市场或者目前仍然在市场中迷茫的探索的人来说，寻找圣杯是每个交易者刚开始的必经之路，只是有些人在探索中发现了所谓的圣杯并不存在，有些人仍然执着于在寻找所谓的圣杯。我作为一个从大学开始十年交易生涯的交易者，刚开始交易时也是认为，交易这个东西绝对是有一个方法或者技术，只是我还不懂或者没有找到而已。于是我开始了边亏损边学习的道路，刚开始在大学身上也就万把块钱，也幸亏也只有这点钱，亏钱是必然的赚钱是偶然的。但是对于交易的兴趣促使我不断地学习，更多的还是不断地跑图书馆找书籍，希望在书籍中找到方法带我通向财务自由之路。从刚开始的《期货市场技术分析》、《零开始炒期货》到后面的《日本蜡烛图分析》、《价值投资》以及关于成交量均线和各种技术指标的书籍,可以说能找到的书籍都被我看了个遍，但是现实情况就是继续亏损，还是没有一本书籍告诉我该如何从交易中赚钱，我一直没能找到交易中的圣杯。

在长期学习各种技术的情况下我依旧迟迟未能盈利，依旧是赚小亏大，一段时间使用均线进行交易，当5日均线上穿10日均线我就买入，跌破十日均线我就卖出，一段时间我喜欢做突破，当价格突破关键的压力位或者支撑位我就买入或者卖出，一段时间使用K线组合，什么三只乌鸦、乌云盖顶、红三兵，企图从K线组合中预测下一日的行情，所有的方法我都尝试过了，但是最后还是不能盈利，这时我开始气馁了，怀疑是否有方法可以从这个市场中赚钱，那些长期能过赚钱的人是如何赚钱的，当时的我认为肯定是有方法，只是那些成功的交易者不愿意透露罢了。

逐渐找到所谓的圣杯的过程是从我开始研究那些从市场中获得结果的交易者开始的，当我开始研究那些成功的交易者的访谈或者书籍时，**我发现那些交易者所强调的是盈亏比、仓位管理、以及风险控制这些要素，他们的交易成功率甚至只有50%甚至更低，但是他们依旧能从市场中赚到钱，这瞬间打破了我原有的认知，我一直觉得成功的交易者赚钱是靠他们准确的判断，他们知道改该从什么价格进场，并能精准的离场。原来判断正确与否并不影响他们从市场中挣钱。他们更多的强调的是建立自己的交易系统，严格的仓位管理，以及及时止损，让利润奔跑**。于是我逐渐开始了交易系统的研究之路。
