#  你的交易结果无非五类：

一、小亏。

二、小赚。

三、大亏。

四、大赚。

五、打平。

把小赚、大亏从你的交易系统中踢出去，只保留小亏、打平、大赚。

why？

小赚会让你错失大行情。

大亏不仅无法让你稳定盈利，还会诱发你情绪化交易。

回顾一下“过程正确”中的小亏、打平、大赚如何发生。

轻仓、止损、浮盈加仓、打平离场、扩大盈亏比这五个基本动作。

这五个基本动作，组合成三个“过程正确”流程：

一、轻仓，止损了，一笔交易“过程正确”了。（小亏）

二、轻仓，浮盈加仓，浮盈消失，打平离场，一笔交易“过程正确”了。（打平）

三、轻仓，浮盈加仓，扩大盈亏比，大赚一笔，一笔交易“过程正确”了。（大赚）
