# 交易真的是一个反复试错的过程吗？

易经是我国的一部哲学著作，并且被广泛地用于解释各种生活现象，尤其是金融交易市场，在这个不确定的市场，没有任何一个人或者事物能够教给你如何交易，唯独这本易经，被称为“交易圣经”，这里面就包括交易行情。易经中的事物发展规律，也就是易经的“阴阳顺逆”理论，通常可以划分为下面7个阶段，这些阶段与行情的发展有一定的对应关系。

1. 起始阶段（乾）：在交易中，这是行情开始变动的信号，可能是由于某个新闻或者大的市场事件引发的。在这个阶段，投资者应当密切关注市场以准备接下来的变动。

2. 发展阶段（兑）：这是行情开始上升或下跌的阶段。如果是上涨市，那么投资者可能会看到有更多的人开始进入市场；如果是下跌市，那么可能会有更多的人开始抛售。

3. 变动阶段（离）：在此阶段，市场开始有明显的趋势，上升或下跌。投资者在这个阶段的行动会对市场有较大影响。

4. 常态阶段（震）：这个阶段市场趋势已经明确，各种预期和信息已经被市场充分吸收和反映出来。行情的变动可能会变得较为平稳。

5. 存在阶段（巽）：这是行情维持现状的阶段， 如果没有新的重大利好或利空信息出现，市场可能会在这个阶段中维持一段时间。

6. 变革阶段（坎）：当有重大的市场变动发生，例如新的政策、技术进步等，行情可能会被推到一个新的阶段。对投资者来说，这是一个新的决策阶段。

7. 完成阶段（艮）：行情到达顶峰或谷底，随后可能会对现有的趋势进行转变或者是开始新的一轮循环。

这些阶段具有一定的周期性，就如同易经所讲述的万物发展阶段一样。了解这些阶段，可以帮助你更好的把握行情，制定交易策略。

比如资金管理（用系数表示头寸大小）：

1. 初六（开头）：行情刚刚开始，处于起步阶段，潜在风险和机会都有，0.3系数小仓位尝试。

2. 九二（初步发展）：行情开始有所进展，但还不够稳定，风险依然存在，需要谨慎对待，0.6系数仓位尝试。

3. 六三（艰难阶段）：行情进入了一个困难和挑战的阶段，可能会遇到一些阻碍和障碍，需要克服困难，此时，市场波动率较大，用0.9系数尝试。

4. 九四（稳定阶段）：行情经历了一些困难后，开始稳定下来，风险逐渐降低，交易者可以考虑进一步参与，1.2系数或者加仓。

5. 九五（高峰期）：行情达到了一个高峰期，市场活跃，机会和风险并存，需要灵活把握，1.5系数或者加仓。

6. 上六（爆发阶段）：行情机会远远大于风险，最好的交易机会，1.8系数或者加仓。

7. 九（收尾）：行情进入尾声，市场开始平静，需要注意市场的健康发展和可能的变化，平仓。

当然交易中，最本质的还是情绪、欲望、念想，这些是交易者们博弈的根本。
