# 什么是滚仓？什么又是浮盈加仓？详细剖析！

先上总结：滚仓是高收益的操作，但其背后同样是极高的风险，一定要谨慎。

而滚仓（指数级增长）+复利模式才是高性价比的策略。注意，滚仓就是指数级增长，而复利是指数级增长的特殊表现，也就是说所有复利都是指数增长，但指数增长并非都是复利，现货才是复利模式，期货更像是线性增长模式。

下面正式开始聊聊滚仓吧。

5000本金，10倍杠杆，一波100%的涨幅，最终盈利是500万，这是滚仓。

浮盈加仓不是滚仓。因为现在市面上对滚仓的定义及方法全部是直接复制粘贴肥宅、比特皇、tony的观点，对于没有什么投资经历的小白而言还是不够通俗易懂。本文旨在通俗粗暴的进行解释。

假设btc现价10000，建仓5000，10倍杠杆。此时btc涨到了11000，涨幅10%，此时你盈利5000。ok接下来的操作很重要了。

1. 浮盈加仓的做法是再追加5000，随后btc涨到了12000，又涨了10%，此时你连本带利是2.5万。（本金两个5000+盈利三个5000）

2. 滚仓的做法是平掉之前的仓位，连本带利10000，再建仓，随后btc涨到了12000，同样的涨幅10%，此时你连本带利是2W。

这么一看是不是没啥区别？但是你只要一直循环操作，当btc涨到20000的时候，涨幅是100%。浮盈加仓最终连本带利是32.5万（其中包含五万本金）。滚仓连本带利是512万（其中包含五千本金）。

为啥差距这么大呢？接下来随我一起剖析一下。

1. 什么是一个完整的建仓周期？

建仓 → 浮盈 → 浮盈 → 平仓出局

2. 什么是一个完整的浮盈加仓周期？

建仓 → 浮盈 → 加仓 → 浮盈 → 平仓出局

3. 什么是一个完整的滚仓周期？

建仓 → 浮盈 → 平仓再建仓 → 浮盈 → 平仓出局

OK，这里再延伸两个概念，同样使用通俗易懂的方式。一个是线性增长，就是10%、10%、10%这么涨。一个是指数增长10％、20%、40%、80%这么涨。线性增长就像你开车踩油门，从起步10迈到20迈到80迈很平稳。指数增长呢就像科技的发展一样，是成倍数的增长，刚开始很慢，越往后越快。这里举个不严谨的例子方便理解，根据确凿证据能证明人类彻底熟练运用火是在40万年前，人类彻底熟练运用电是在200年前，车大概是100年前，互联网是55年前，移动互联网是30年前。也就是说电被熟练运用后人类科技得到了飞速的发展。这么一比之前那40万年跟闹着玩儿一样。扯远了，言归正传。

到这里我们再类比一下：

普通的建仓就是线性增长，严格意义上合约不算线性，但姑且先这么类比，便于理解。

浮盈加仓就是线性增长的基础上再加仓。

滚仓则是成倍的指数性增长。

而滚仓（指数级增长）+复利模式才是性价比较高的策略。
