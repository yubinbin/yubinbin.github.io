# 有什么较好的仓位管理的方法?

仓位管理还需要方法？

真是醉了，两个字能解决的问题。为了凑足500字，我还得多打四百九十八个字。

轻仓，轻仓，轻仓，轻仓。

第一个轻仓：

资金上的轻仓，至少保证你的资金足够交易100次。死也要慢慢死，用钱换经验。钝刀子割肉才能感到痛，才能长记性。

第二个轻仓：

心理上的轻仓，鉴于很多投资者资金的1%根本不够开仓，就只能采用心理上的轻仓。开仓后能安心去睡觉吗？能就是好的仓位。

第三个轻仓：

截断亏损的仓位，亏损的仓位及时平掉。盈利的仓位，不要让其变成亏损。亏损的单子，仓位再轻都是重仓；盈利的单子仓位再重，都是轻仓。

第四个轻仓：

浮盈加仓，保住利润。浮盈的时候该加仓就加仓，只要能做到加仓不加风险。干就完事了。

回答一个很好玩的问题：轻仓能赚钱吗？(没错，我是在凑字数）

**答案其实很明显了，如果你轻仓都赚不了钱，你重仓只会死的更快。**

如果你轻仓能赚到钱，你又何必重仓。

假设你有1000的资金，每次开仓只用资金的10%。也就是100万。

如果你能稳定的盈利，你的资金早晚会到2000万，这时候你依然用10%的资金开仓，你能动用的头寸规模已经变成了200万。

这时候的200万，对你来说依然是轻仓。然而从资金上来说，你已经能开出以前2倍的仓位了。而你的风险承受能力却没变。

这就是轻仓的魅力。

也就是所谓的，加仓不加风险。
