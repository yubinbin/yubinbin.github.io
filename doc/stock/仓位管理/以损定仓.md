
# 以损定仓

以损定仓，最大单笔交易亏损不能超过总仓位得2%，保守点可以定位1%，大环境好时可以用2%的止损。

严格止损时，多次止损，如果胜率较低时，**盈亏比小于3**，长期下来会亏损，所以胜率低时加大盈亏比。

总资金亏损2%时可买入仓位，仓位大小与止损大小比例：

总资金： 40000
总资金止损比例： 2%

| 40000 | 2% | 40000*2% = 800 |

| 20000 | 4% | 40000*2% = 800 |
| 16000 | 5% | 40000*2% = 800 |
| 13000 | 6% | 40000*2% = 800 |
| 11000 | 7% | 40000*2% = 800 |
| 10000 | 8% | 40000*2% = 800 |
| 8800 | 9% | 40000*2% = 800 |
| 8000 | 10% | 40000*2% = 800 |
| 7200 | 11% | 40000*2% = 800 |
| 6600 | 12% | 40000*2% = 800 |
| 6100 | 13% | 40000*2% = 800 |

单品种的仓位永远不超过30%。也就是说，永远不要重仓一只标的。

买3只不同类型得股票，仓位占比各占30%。

总仓位 * 30%  

40000 * 30% = 12000

每只股票金额不能大于12000，所以总金额40000,现在每只股票可买入最大金额为12000。再根据止损调整具体仓位。
