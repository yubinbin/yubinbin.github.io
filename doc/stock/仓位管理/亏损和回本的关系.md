
# 亏损和回本的关系

我认为所有的交易员进入市场的第一课就是风险控制，只有让自己能够在市场上存活下去，才能够有未来。你有本金，才能有一切。可悲的是，有数据表明，大部分新手交易员在进入市场的一年里就输了个精光，有的还倒欠交易所一笔。

那么，如何控制风险？如何保住本金安全？

**单品种的仓位永远不超过30%。也就是说，永远不要重仓一只标的。为什么？**

因为只要你还在交易市场交易，那么就一定会遇到黑天鹅事件，这个事实已经有无数人证明了，这种黑天鹅事件可能就在下一个交易日，可能是明年，也可能是十年后，也可能就在你打算金盆洗手的前一天。

如果你真的想成为交易市场里的寿星，那么请务必牢记这条规则。下面这个表格详细地说明了亏损和回本的关系，满仓交易，一次黑天鹅事件就足以让一切化为乌有。

| 本金亏损幅度 | 回本需要的涨幅 |
| :-----:| :----: | 
| 10% | 11% |
| 20% | 25% |
| 30% | 42.86% |
| 40% | 66.67% |
| 50% | 100% |
| 60% | 150% |
| 70% | 233.33% |
| 80% | 400% |
| 90% | 900% |
| 100% | 永远无法回本 |


能否控制好风险，是一名交易员能否长期在市场生存下去的决定性因素。几乎所有失败的交易员都死于风险控制失败上。

但是在风险控制上，新手和老手又有非常明显的区别。

交易大师往往死于长期的过度自信，因为长期的交易顺利会极大地膨胀人的内心，让人开始藐视市场，无视风险，导致在某次交易中重仓逆势抗单，最后被一波带走。

我看过很多的失败案例，发现几乎所有有成就的交易大师都是这么失败的，他们赢了一辈子，结果往往因为一次大的错误而一夜回到解放前。我从未见过一个交易大师因为30%的仓位而破产。

破产的、逃亡的、入狱的、跳楼的......几乎百分之百犯了重仓逆势抗单的错误。

交易新手则往往死于没有交易策略和频繁交易，总是想博取短线收益。

为何新手总是喜欢做短线？因为做短线刺激，可以刺激多巴胺的分泌，体会交易的快感。殊不知短线交易有很多苛刻的条件，对交易能力和心性控制的能力要求极高，小白做短线，就如同一个毫无锻炼基础的人直接去爬珠穆朗玛峰。结果可想而知。

以上都是大局观，从整个交易生涯来讲如何进行风险控制。关于风险控制的具体操作方案，我会在交易系统中进行详细的叙述。
