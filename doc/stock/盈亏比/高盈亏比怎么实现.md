# 交易系统的高盈亏比怎么实现？

交易系统的高盈亏比怎么实现？

首先你要保证你的交易逻辑是正确的，必须是截断亏损，让利润奔跑。你想要提高交易系统的盈亏比，就是截断亏损的时候尽可能的降低单次的亏损，而有了盈利以后就尽可能的让利润奔跑，不要轻易落袋为安，这样调整以后，你的胜率就会变低，盈亏比就会变高。

但是很多人却在追求表面的东西，总是在入场环节下功夫，试图通过各种方法，主观判断，添加过滤，剔除一些假信号，研究各种高盈亏比的走势形态，比如盈亏比要多达到多少才会入场等，研究各种所谓高盈亏比的战法，都是在表面动手术，没有深入本质。

关注我的人我都知道，**我经常说过入场只是一个试错的开始，因为走势是不确定的，任何主观层面的入场环节都是很难证伪的，如果你的样本足够长，你会发现，不管你怎么在你的入场环节上优化，你最终都会发现基本上都不靠谱，因为你把一些假信号过滤掉的同时，也把一些真正潜在的大行情也过滤掉了。**

所以提高盈亏比最本质的方法就是降低你的胜率，这个效果非常明显，

**那么如何降低你的胜率呢，有两种方法，就是缩小你的止损幅度和放大你的止盈空间。**

比如原来你的止损是100个点，你把它缩小到50个点，那么你的胜率立马就降低了，你的止盈原来是50个点，那么你把它放大到100点以上，你的盈亏比也就立马掉提高了，因为止损50个点的概率要大于100个点，而止盈50个点的概率要大于止盈100个点。

天下K线是一家，不管是期货外汇还是股票的交易当中，你想要提高交易系统的盈亏比最有效的方法就是降低你的胜率，这也是最本质的方法。千万不要本末倒置，不断优化，追求完美，这是不存在的，不要陷入一条不归路。

高胜率低盈亏比和低胜率高盈亏比，这两种模式哪一种更有效？

从理论上来说，我认为高盈亏比低胜率有更大的优势取胜。

因为高胜率低盈亏比通常都是抓小放大，赚到一点利润就赶紧落袋为安，而亏损的时候很容易死抗，这样你可能连续小赚10单1单大亏就让你回到解放前。而且高胜率低盈亏比模式，会让你陷入不断的追求高胜率入场中，不断的寻求高胜率指标，不断的寻求高胜率圣杯从而浪费很多青春。

**而低胜率高盈亏比你不会再专注于入场信号**。这个转变就很重要，因为入场相对其他环节不重要，**你会把重心放在出场上，而交易最重要的也是出场，这种模式就是典型的趋势交易，胜率比较低，所以原则上它是一种带有试错的概率交易模式**。每次出手都是小幅亏损，错了就截断亏损，对了就让利润奔跑，这样长期来看你连续小亏10单，但是作对一单就能覆盖掉前面10单的小亏磨损。

所以长期来看，低胜率高盈亏比的交易模式，更有优势在不确定的市场中长期稳定获利，当然也正是因为胜率低，会让90%的人没办法坚持，这也是为什么交易市场90%的人亏损的根源所在。
