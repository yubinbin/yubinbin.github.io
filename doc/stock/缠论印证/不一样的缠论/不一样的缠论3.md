# 不一样的缠论（高阶）3

价格与均线的关系

市场经济学的原理告诉我们：价格围绕价值进行上下波动。

我们转变一下思路，用均线来代替这段周期内的平均价值，得出来的结论就是：价格围绕均线进行上下波动。

把这个结论放回到市场中去检验一下，发现这个结论就是千真万确，的确如此！

这个结论与缠论什么关系呢？

打开任意一个市场品种的走势图，设置任意一条均线，仔细体会一下价格的趋势与均线之间的关系。

归纳起来，就是五种关系：

（1）价格上穿均线；

（2）价格从上方向下回抽均线；

（3）价格下穿均线；

（4）价格从下方向上回抽均线；

（5）价格与均线胶着，没有趋势和方向。

第五种情况的标的，都是垃圾，看都不要看一眼。我们只看前面四种情况。

第一种情况，价格上穿均线，这就是缠论所讲的上涨趋势啊！

第二种情况，价格从上方向下回抽均线，这就是盘整走势啊，也可以看成一个大级别的中枢结构啊！

第三种情况，与第一种情况相反，价格下穿均线，这就是下跌趋势。

第四种情况，与第二种情况相反，这也是盘整走势，可以看作下跌中的一个大级别的中枢结构。

缠论所讲的趋势、盘整结构类型，本质上来说，都是对价格围绕价值进行上下波动的情况分类。
