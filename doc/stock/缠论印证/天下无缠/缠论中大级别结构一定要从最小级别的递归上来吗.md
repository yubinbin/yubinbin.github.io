# 缠论中大级别结构一定要从最小级别的递归上来吗？

天下无缠

我从你这个问题里听出来一点情绪，觉得递归麻烦对不？

为什么要递归？是因为你要确定最小级别，并且保证这个最小的级别在任何周期图上看都是那个最小的级别对么？

缠师也说过要确定本级别就要确定次级别，那么次级别如何确定就变成了一个问题，因为不能无限缩小下去，所以定义了最小级别一分钟，对么？

换句话说，你只要能定义最小级别，你就在任何周期图上定义任意级别，对么？

你一定用过交易软件，如果是我，我会怎么解决这种递归的麻烦？我会在一分钟图上定义一个一分钟级别，然后用画图工具标注出来，比方一个矩形的红色框框，你设定默认这个红色的矩形在任何周期图上都可以显示，那么五分呢？三个红色矩形的重叠么不就是了，然后你再用一个黄色的矩形标注出来，以此类推，所以递归实际上不麻烦，比方你用黄色矩形框出来一个五分级别，你把这个黄色框框复制，往右边移动，去找一个差不多大的，那么他就是五分，多一点少一点无所谓，为什么？因为这个平移过来的黄色框框，肯定大于一分钟，但是不够三十分钟，那么他就是五分钟，即使两个五分，依然还是五分，不够三十就是不够，没升级。

所以不是说每次递归都需要去重新递归一分钟。
