# 关于级别的初次讨论

孙北漠与唐南溪

级别这个东西我觉得有必要单独拿出来讨论一次，我敲下这个题目的时候实践上还没有想好要怎么写，只是脑袋里大概有个念头。

关于几年前的一次对话。

首先我不是职业证券从业者，我有一份“正经”工作，所以我并不知道职业的证券从业者到底是怎么个事儿，我只是做好我自己的交易。我的那位老师再一次闲聊的过程中说过这么一段话：“国家对于证券从业人员颁发的职业资格，如果按照自己的标准，九成以上是不合格的，我觉得他们连客观的分析这个市场都做的不好”

大概是这个意思，比方以前讲的同级别分解和非同级别分解，就是为了不割裂走势，也就是为了客观的分析这个市场，你从任何周期的走势图中，拿出一段来，再放到任意周期图上，都不会产生变化，一就是一，二就是二，明明白白，清清楚楚。这件事很有意义，如同人之情绪，思虑不定，往往容易坏事。

另外这里我再多提一句，缠师的原文中有一句原话，级别的大小和周期图的大小没有必然的联系，这句是原话，具体在哪一篇原文里，我忘了，不信的朋友可以自己检索原文。

之所以引用了上面这一段是因为我们要讨论的是级别，所以我们必须要在一个统一的语言环境里，这是前提。

关于三进制升级的一段玄学（以下的这段文字是有天我看到我某篇文章下面有个人评论了，然后突发奇想扯了几句，如果你看的时候感觉生理不适，请自动掠过该篇）

那个知友的问题是“晕了，9笔也升级？”

以下是我的回复：

我想起了另一件事，古代帝王皆称九五至尊，九五亦在十之下，不成十便是不成十，哪怕9.5，不升级就是不升级，三进制就是三进制，不够倍数九那就是皆为九之下，不升级，升级之后统在一起便是新的级别的三的起始单位，重新计算。发现什么问题没有，祖师爷很恶趣味的绕开了十，永远也不会有十的出现，一但超过，便自动跳过，去另一个级别看问题，古代帝王称为九五至尊，便是告知九天之外的仙人，我依然为人，也就是三进为九便是一，不到十我便依然是人，可逍遥红尘，破了便与规律合二为一，同时失去自由意识。怎么选？大道五十，天衍四九，人遁其一，那个一便是人道，非天道，即使身陷五浊恶世，仍有一线生机，貌似和易经里的巽卦有异曲同工之妙。我瞎说的，你当个笑话看便可，不保真，保胡扯。

为什么是三进制这个问题，我没办法回答，因为无从考证，我开头说过，我并非职业证券从业者，只是一个拿来主义的人。

我们前面讨论过很多级别的划分问题，但是貌似没有讨论过究竟应该选择什么样的级别进行操作的问题。

先说我的答案，无法确定级别的选取。

是不是很失望？别失望，我帮你排除两个选项可好？

不做一分和五分的级别。

有人可能会疑惑，因为我前面的文章里写过一和五的操作对吧，但是如果你看的仔细一点，会发现，你看我操作的1和5，都不是单独存在的，我说的不做是不做独立的1和5，但是1和5是我们介入一段30分级别以上行情的工具。也就是你的视角至少应该是在30分级别以上，至于30分级别以上多大的级别就看各人了。

至于为什么我排除了这两个，是因为理论上可以，具体实践下来，虽然也能做出来，但最后的结果往往是不赚钱。

它符合规律吧，符合，理论上实际上都符合，但是结果就是不如人意，就这么个事儿。
