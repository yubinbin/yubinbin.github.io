# 交易中有确定性吗？为什么？

有，就因为有确定性，所以才有“从长期看是盈利的”这样的说法。

至于什么叫确定性，说出来你或许又会觉得一文不值，但是事实确实就是这样子。

来来来，我们一起朗诵高中教科书：

价值规律：商品的价格围绕着商品的价值上下波动。

没错，教科书白纸黑字告诉你了，这就是确定性。跌下去了必然会有上来的时候，上去了，也必然会有跌回去的时刻。

什么？你觉得这什么都没说？那就只能说明你从未领悟其中的精髓。

价值规律，就是市场经济的核心，市场的一系列复杂的行为表现，归根到底就是它在起作用。如果我们将价值规律，换一个说法，或者换一个角度来看，就会变成，当大家都在吹捧一个泡沫的时候，总有一群理性的人，他们知道泡沫太过了，就通过大量的做空将价格压下去。当商品的价格进入低谷时，总有一群理性的人，他们认为价格太低了，通过大量的做多，这时候商品价格重新反弹上去。

我换了一个更加具体的说法，把价值规律重新说了一遍。但是有一个很有意思的地方，那就是我划重点的地方，“理性的人”。大家可以想象一下，这些所谓的理性的人究竟是什么人？聪明人？金融财团？资本家？好吧，我们暂时不纠结这个理性人。

然后，我们归纳以上的说法，继续对价值规律进行深挖。我提出一个问题，为什么理性的人愿意去做这样的好事？正因为他们的理性，才让市场得以可以纠正自身的错误，继续稳定运行下去。

凭什么？相信大家应该很明白，这些理性人之所以这么做，是因为他们可以通过高卖低买（割韭菜）的操作实现市场的套利行为。

而这种套利的行为（做多做空），正是市场赋予市场参与者的工具。市场参与者利用市场给与的工具，通过套利作为源动力，对市场进行长期的维稳工作。而市场为了鼓励他们去套利，会以奖赏的方式（利润）回馈他们。

**因此，说到这里，市场的核心实际上就在于套利。**

既然套利是市场赖以维护自身稳定的核心，那就意味着，理性的市场参与者在长期的市场参与过程中必定得到利润。

然后我们又回到刚才问的问题，谁是理性人？

他们一定很聪明！

他们一定有庞大的资金！庞大的资金让他们可以纠正非理性的大多数。

他们必定是少数。（盈利的必然是少数人）

看到这里，或许还会有人说，这等于没说！

其实不然，你如果真的坚持理性的投资策略，从市场理论出发，长期看必定是盈利的。

当然，你必须得找到符合市场规律的商品，去做这个“套利者”。

例如股票，实际上绝大部分股票并不符合正常的商品。其价格曲线非常极端，她就不是正常商品。

例如指数，指数就相对来说好很多，基本上符合涨多了必然会下去，跌多了必然会上来的规律。
